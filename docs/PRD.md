# PRD — Cova iOS 原生 App v1.0

## 1. 产品定位

**「会创作、可授权的音乐流媒体」**。一个 App 同时是：

- **网易云音乐式**的发现与播放产品：歌单中心化、场景推荐、沉浸播放器、个人音乐资产；
- **Suno 式**的创作产品：一句话生成、双候选 Demo、创作资产库；
- **音乐 Agent**：统一会话框承载「找歌」（find-my-song，曲库检索推荐）与「做歌」
  （one-step 生成）两个意图，思考过程可见；
- **Cova 独有闭环**：曲库曲目与 AI 生成物均可商用授权（co 币）——这是参照物没有的。

核心洞察：后端 API 本身就叫 `find-my-song`——找歌与做歌是同一个 agent 的两个意图。
首页会话框是唯一入口：说「给我来点适合咖啡馆的 Lo-Fi」→ 返回歌单/曲目推荐卡；
说「做一首夏日广告配乐」→ 返回计划确认卡片 → 双 Demo。

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| 内容创作者（短视频/播客/广告） | 找可商用 BGM：按场景/情绪筛选、试听、收藏、下载授权 |
| 小微商家/市场运营 | 一句话生成专属配乐，快速试听迭代 |
| 音乐爱好者 | 歌单发现、沉浸播放、AI 音乐人追踪 |

## 3. 信息架构

```
┌─ 左侧抽屉（内容与网站左边栏统一）──────────────┐
│  首页 / 曲库 / 歌单 / 创作（会话列表，AI 渐变高亮） │
│  ───────────                                │
│  我的收藏 / 我的歌单 / 我的创作 / 已下载歌曲        │
│  会员 / 企业服务（跳网页）                      │
│  ───────────                                │
│  我的（头像：余额·套餐·设置·关于）                 │
└───────────────────────────────────────────────┘

主区域（iPhone）：
  首页  ＝ 问候语 + 会话输入框（液态玻璃卡）+ prompt starter chips
         + Feed（今日推荐歌单大卡 / 场景歌单横滑 / 继续聆听 / 你的创作 / AI 音乐人专栏）
  曲库  ＝ taxonomy 三级级联筛选 + 搜索 + 曲目列表
  歌单  ＝ 官方歌单网格 → 歌单详情
  创作  ＝ 会话列表 → 会话详情（对话流 + 计划卡 + 双 Demo + 补充制作）
  播放器＝ 全局 MiniPlayer（液态玻璃悬浮）→ 全屏播放器（歌词/波形进度/±15s/循环/收藏/分享）
```

- 导航：DeepSeek 式左侧抽屉（左上 logo 唤起 + 边缘右滑手势），**无底部 TabBar**——
  首屏完整留给「会话框 + feed」。抽屉项与 web `SideRail`（曲库/歌单/创作）+ 用户菜单
  （收藏/歌单/下载/设置）对齐。
- 会话框：模式 chips「找歌 / 做歌」（默认自动判断）+「深度思考」开关（展开 agent
  thinking 流，SSE `thinking` 事件驱动）。
- iPad：抽屉自动转 sidebar（`sidebarAdaptable`）；v1.0 不含 iPad 专版布局。

## 4. 功能清单（v1.0）

### 4.1 发现与播放（M1）

- 匿名浏览公开内容（首页/曲库/歌单）；AI 与收藏需登录
- 首页 feed 分区：今日推荐歌单大卡、场景精选横滑、继续聆听、你的创作、AI 音乐人专栏
- 曲库：多维筛选（scene/mood/style/instrument/attribute/energy/vocalType/bpm/duration）
  + 搜索 + 分页 + 排序；曲目行含波形、标签、时长、收藏
- 歌单：列表、详情（封面 fit/焦点）、收藏（save/unsave）
- 播放器：队列、循环三态（off→all→one，无 shuffle）、±15s 快进退、进度 seek、
  波形进度（`waveformPeaks`）、锁屏/耳机/蓝牙媒体键、后台播放、静态歌词视图、
  播放上报（`source: "app-ios"`，幂等键去重）
- 登录：邮箱+密码（Bearer access+refresh，Keychain 存储，401 single-flight refresh）
- 我的：用户信息、套餐/余额展示、收藏/歌单/创作/下载入口、主题跟随系统、设置、关于

### 4.2 Cova AI 创作（M2）

- 会话列表（抽屉「创作」）与会话详情
- 对话流：SSE 优先（`thinking`/`text`/`plan_card`/`error`/`done` 事件），
  降级轮询（10s 无首事件/30s 静默/3 坏事件/done 前 EOF → 5s 轮询 plans，不并发）
- 计划确认卡片：标题候选/风格分析/歌词/参数/credits 展示，12 种状态中文文案；
  严格归属校验（`sourceMessage.messageId === clientMessageId`）才解锁「开始制作」
- 双 Demo 硬规则：只取前两个候选，双双 settled 才算终态；候选支持试听
  （私有音频先授权下载到沙盒再本地播）、收藏、分享
- 补充制作：完整音频交付进度（`delivery_preparing` → `fullMediaReady`）
- 生成完成本地通知（深链回会话）；生成中退到后台可恢复（服务端为事实源）

### 4.3 资产与打磨（M3）

- 下载管理（状态机：下载中/暂停/完成/失败；Wi-Fi 仅下载开关）——**UI 入口待 D12
  合规放行**
- 会员权益展示（不售卖）；AI 音乐人专栏（A01–A15）
- 空态/加载/错误态全覆盖；Dynamic Type / VoiceOver；Reduce Motion

### 4.4 明确不做（v1.0）

- 任何购买/充值入口（D12）；社交/评论/动态；播客/直播；DAW 级编辑、分轨、
  上传 cover；自由多轮工具编排（锁定一步模式）；远程推送（本地通知兜底）；
  iPad 专版布局；Android（归 `多端/mobile` 工程）

## 5. 成功度量

- 核心漏斗：启动 → 会话框输入 → 收到找歌/做歌结果 → 试听 → 收藏/（合规后）下载
- 质量：首屏 ≤1.5s（热启动）、滚动 60fps、SSE 首事件 ≤10s、崩溃率 <0.5%
- 验收：M1/M2 里程碑验收口径见 `PLAN.md`；发布门见 `release-runbook.md`
