# iOS 接口对齐手册（可执行版）

> **用途**：web 发版 / 路由变更 / 字段或错误码变更之后，判定「iOS 需不需要改、改哪里、怎么证明改好了」。
> **每条命令都在写这份手册时实跑过**（2026-10-26 04:5x +08，生产 2.77.62/`53994040`——**该 SHA 已过期**），输出见 §2。
> **基线 SHA（权威）**：2026-10-27 06:2x +08 实测 `curl -s https://covalink.cn/api/health` ⇒ sha=`577b1a19`、version=2.77.62、uptimeSec=72454。文中出现的 `53994040` 是**上一版载体提交（已过期）**，只作历史记录，不得再当结论引用。
> 跑不通的命令没有写进来；机器相关的差异（模拟器名、路径）在对应步骤里给了取法。

## 0. 什么时候用

| 触发条件 | 从哪一步开始 |
|---|---|
| web 发了新版本 | §1 步骤 1（取基线）→ 2 → 3 → 4 → 5 |
| 只改了 UI / 文案（无 `src/app/api`、`src/lib` 改动） | 步骤 1 → 3，若守卫绿则 §1-4 判「不受影响」，写一行即可 |
| 新增/删除路由 | 步骤 3 会直接红（守卫）→ 步骤 4 → 5，并 `--update` 基线 |
| 某个错误码行为变了（402/409/413/429） | §1-4 的「必须改」判据 + §4 三段模板 |
| 客户端要加新端点 | 先跑步骤 3（守卫会报「基线里没有的新增路径」），再补 DTO/服务层/测试 |

## 1. 五步判定流程

### 步骤 1 · 取当前生产基线（唯一事实源，不靠印象）

```bash
curl -s https://covalink.cn/api/health
```

判据：`version` + `sha` + `frozen` 三格都要记进盘点的 §0；`frozen=true` 时**先问助理部**再继续（写流量被冻着，行为可能不是最终态）。

### 步骤 2 · 取「已发布树」的 API 源码（不是本地分支）

```bash
mkdir -p /tmp/cova-ios/web539
cd 多端/web && git archive <步骤1的 sha> src/app/api | tar -x -C /tmp/cova-ios/web539
```

为什么不用本地工作树：工作树可能停在别人的 feature 分支且是脏的。**对齐的对手方是"已发布的那棵树"**，不是"我此刻的磁盘"。

### 步骤 3 · 跑调用面守卫（两条命令，都要绿）

```bash
cd '多端/ios app' && swift Scripts/check-endpoint-drift.swift                          # 本地工作树
COVA_WEB_ROOT=/tmp/cova-ios/web539 swift Scripts/check-endpoint-drift.swift             # 已发布树
```

判据：两条都 `✅ 零漂移` + `EXIT=0`。任一条红 ⇒ 走步骤 4，**不许**直接把基线 `--update` 掉（那等于把漂移写成事实）。

### 步骤 4 · 差异分级（四档，定义见 §3）

对每条差异只问三个问题，按顺序：
1. **iOS 会因此拿不到用不了的东西吗？**（404 / 字段被删 / 必填变必填）⇒ 必须改
2. **iOS 现在会因为不知道它而说错话吗？**（错误码没分诊、文案写死）⇒ 必须改 或 可延后（看用户是否可见）
3. **只是多了能力/多了字段？** ⇒ 不受影响（写一行"纯增量"）

拿不准的**不许猜**：进「未核实」，并写清「缺什么证据 + 怎么取」（§3 第四档的要求）。

### 步骤 5 · 落盘（三段写法 + 计数口径）

见 §4 与 §5。落盘位置：`归档/qa-evidence/多端对齐-<YYYYMMDD>/iOS.md`，写完更新 `归档/qa-evidence/INDEX.md`。

## 3. 分级判据（四档）

| 档 | 判据（可机械判断） | 本仓例子 |
|---|---|---|
| **必须改** | 不修就有**用户可见的错误行为**：动作做不成、话术错、钱算错、状态卡死 | `plans/start` 的 402/429 掉进 `CatalogService` 兜底 ⇒ 屏上 `HTTP 402` |
| **可延后** | 不修不影响既有路径，但契约已经不一致（DTO 缺字段、注释断言已被推翻、闭集少一档） | `ledger` 新增 `wallet` 段而文件头仍写"只有 {entries}"；`filter` 少 `generated` |
| **不受影响** | 纯增量（多字段/多可选参数/多路由），或变化方向对客户端**只有更早期终态**这类改善 | `/auth/me` 多了 `nameChange`；Lyria 停滞检测让 job 更早 `failed` |
| **未核实** | 拿不到证据（缺凭据 / 机器不可达 / 需要花钱），**且不许用"大概"补** | cova-api 版本（VPS 内网）；413 的真实触发（需零余额 + ready 计划卡） |

第四档的硬要求：每条都要写「缺什么证据 + 怎么取」，且**不许**在别处引用它当结论。

## 4. 三段写法模板（「必须改」与「可延后」都按这个写）

| 段 | 写什么 | 反例（会被退回） |
|---|---|---|
| **触发条件** | 什么请求 / 什么状态 / 服务端哪个文件哪一行抛出 | 「服务端返回 402 时」← 没说什么时候会 402 |
| **动作** | 改哪个文件的哪个类型/方法，**为什么这么改**（一句话） | 「加个错误处理」 |
| **验证** | 一条能重跑的命令或一个能复现的操作 + 断言（含变异自证更好） | 「测试通过」 |

真实样例（摘自 `归档/qa-evidence/多端对齐-20261026/iOS.md` §3）：

> **触发条件**：已登录、持有 `status=ready` 的计划卡、钱包余额 < 所需 co ⇒ `lib/one-step/generation.ts` 抛 402 `{error, code:'credits_insufficient', balance, required}`
> **动作**：`StudioService.startPlan` 改 `performCoded`；非 2xx 交 `StudioStartFailure.classify`（复用 `StudioCreateRejection`，不另写词表）
> **验证**：`StudioStartFailureTests` 14 条钉文案不含 `402`；变异自证 3 红且还原后 md5 一致；`check.sh` EXIT=0

## 5. 计数与引用口径

- **写「N 项」必须同时给「对应多少行」**：读者数出来的行数不等于项数（一项可能在表里占多行 + 回指行）。
  例：`必须改 2 项（§2 中对应 4 行：402/429 各一行 + 两行回指）`。
- **数字必须由命令产出**，不许手数：`grep -c` / `awk` / 脚本输出原样贴（本仓踩过：手数 36 条，实际 38 条）。
- 引用别处的结论要写清"哪一版"（当前=`2.77.62/577b1a19`，2026-10-27 06:2x 实测；旧的 `2.77.62/53994040` **已过期**），否则一周后没人知道它还成不成立。

## 6. 踩过的五个坑（含修法）

| 坑 | 现象 | 修法 |
|---|---|---|
| 包测试用 `-project Cova.xcodeproj` | `EXIT=66 Scheme CovaCore is not currently configured for the test action` | `cd Packages/<pkg>` 后用它自己的 scheme |
| 守卫跑在 `/tmp` 下的树 | 277 条路由**一条都不匹配** | 脚本已对两边做 `resolvingSymlinksInPath()`（commit `f0594f0`）；自己写类似脚本也要做这一步 |
| 新加 `.swift` 到 `Scripts/` | `❌ D12：1 个 .swift 既不在扫描面内…` | 在 `d12-copy-check.sh` 的具名排除加 `Scripts/*.swift`（**别用 `*.swift` 通配**） |
| 用 `edit` 改 Markdown 表格 | 相邻行被吞、两行并成一行 | `old_string` 只覆盖待删文本；改完 `awk` 数竖线数 |
| 中途清 `/tmp/cova-ios` | 下一轮命令 `No such file or directory` | 多轮任务只在**全部结束**时清目录，中途只清文件 |

## 7. 与门禁的关系

| 判据 | 在 `Scripts/check.sh` 里吗 | 为什么 |
|---|---|---|
| 测试数基线 / 覆盖率 / D12 文案 / 平台中立性 | **在** | 不依赖外部环境，任何机器都该绿 |
| 端点漂移守卫（本手册 §1 步骤 3） | **不在** | 需要同机有 `../web` 源码树；把环境依赖写进发版门禁就是假红（AGENTS.md v2.77.56 的教训） |
| 契约分级判定（必须改/可延后…） | 不在，也不可能在 | 这是判断，不是断言；它的产物是 §3 那四档 + 三段写法 |
