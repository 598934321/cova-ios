## 同一次点击也暴露了一个真缺陷（已登记 §7 #53）

`25-checkin-after-tap.png` 里余额那一格还是 **19315**，而服务端此刻是 **19325**。
代码在签成之后确实 `await session.loadMe()` 重读过，但屏上没跟上 ——
两个嫌疑：① 截图发生在重读回来之前（时序）；② `loadMe` 的"同身份重复请求合并"
把这一次重读吞了（那是 04/11 共读一份账时的既有设计，见 `LoginAndMine` 里那段注释）。
**不因为腿绿了就把它写成一格"已过"**：判据是"签完之后余额要跟着变"，
而这张图证伪了它。修法与结论记在 §7 #53。
