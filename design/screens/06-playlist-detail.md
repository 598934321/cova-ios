# 06 · 歌单详情（头图折叠 + 曲目列表）

> G2 逐屏规格。基准 393×852pt。要点源：`inventory.md` 行 06。
> 数据源：`GET /api/playlists/:id`（api-contracts §2，`tracks[]` 为**普通列表投影**）。
> 曲目行规格唯一源：`../components.md` §1；通用状态规范源：`17-state-gallery.md`。

## 1. 屏与上下文

- **层级**：push 进入 05（或 01）之上的详情屏，入当前页签栈；系统左缘右滑返回。
- **入口**：05 网格卡 / 01 今日推荐大卡 / 01 场景精选横滑卡 / 12b 我的歌单 /
  深链 `playlists/:id` / 07 曲目详情「所在歌单」。
- **互链**：TrackRow → 播放（02 全屏播放器 + MiniPlayer）、长按预览、⋯ 菜单（→ 07 曲目详情、
  → 16 音乐人主页）；收藏状态变化回写 05/12b。
- **返回**：退栈到来源屏，保留其滚动位置；从深链进入时返回 → 05。
- **导航条**：左上系统返回「‹」（本屏是 push 屏；外壳无抽屉/品牌钮，04 §1）。

## 3. 区块规格

### A 导航条

- 初始透明叠在头图上（白字），滚动越过折叠阈值后淡入 `material.navGlass` + `color.fg` 标题
- 标题：`type.headline`；返回钮 / 收藏钮均为图标按钮 ≥44pt（TG-03）
- 折叠阈值 = 头图文本区上沿抵达导航条下沿（几何推导，非新增 token）

### B/C 头图与标题区

- 封面：宽 = 屏宽，`1:1`（比例缺口 TG-10，与 05 共用「封面比例」维度）；裁剪按
  `coverMedia.fit` + `focalX/focalY`（焦点偏移不得裁掉标题遮罩区）
- 底部遮罩：自下而上的深色渐变带（强度缺口 TG-12），承载 C/D 文本，保证白字对比度 ≥4.5:1
- 标题：`type.largeTitle` / 白；`titleCn ?? title`
- 元信息：`trackCount` + `totalDuration` 折算 + `curator`，`type.subhead` / 白 80%（TG-13 透明度档），
  数字 `type.mono`
- 折叠后：标题/元信息消失，仅导航条标题保留；封面缩为导航条下沿的窄条直至完全滚出
  （共享元素过渡，`motion.duration.normal` + `motion.curve`）

### D 简介

- `descriptionCn ?? description`，`type.callout` / 白 80%；最多 3 行，超出「展开」文字钮
  （`type.subhead` / 白），展开不折叠回（本屏内）

### E 操作行

- 「播放全部」：主按钮规格——高 50（TG-07）、`radius.capsule`、`gradient.brandButton` 底 + 白字 +
  `elevation.primaryButtonShadow`，图标 `play.fill`；宽度 = 屏宽 − 2×`spacing.pageGutter` 减去收藏钮占位
- 「收藏」次按钮：同高 50、`color.surface` 底 + `color.fg` 字 + 1pt `color.line` 描边（TG-04）；
  已收藏态：`color.accentSoft` 底 + `color.accentText` 字 + 1pt `color.accent` 描边
- 吸顶：滚动后 E 行吸附在导航条下方（玻璃底 `material.navGlass`），保持两钮可点
- 符号裁决：**收藏用书签语义**（`bookmark.fill` / `bookmark`），非爱心——
  `saveAction.kind === "bookmark"`，爱心留给曲目收藏（03/07）。`inventory.md` 行 06 写「♡」，
  以本条为准（待 G2 验收确认，见「待裁决 1」）

### F 曲目列表

- TrackRow（`../components.md` §1）逐行；行间分隔 `color.lineSubtle` 1pt（TG-04），首行不加分隔线
- 列表容器左右 `spacing.pageGutter`；顶部 `spacing.lg` 与 E 行分开
- 播放中行：标题 `color.accentText` + 音量 symbol 动画（components §1 变体）
- 不显示行内标签胶囊（与 03 区分：本屏信息焦点是「顺序」）

## 4. 状态变体

- **加载（首载）**：头图区 = 方形 `color.surface` 呼吸块 + 两条文本骨架；操作行 = 一长一短两胶囊骨架；
  列表 = 6 行 TrackRow 骨架（封面 48 方快 + 两条文本条），全部 `color.surface` 呼吸（17-S1）
- **空态**：`tracks` 为空数组 → 头图/标题/操作行照常，列表区 17-S2 空态：插画位 +
  「这个歌单暂时还没有曲目」+「歌单可能刚更新，下拉看看」+ CTA「返回歌单广场」→ 05。
  「播放全部」置灰禁用（`color.muted` 底，components §10 禁用态）
- **错误**：首载失败 → 整屏错误态（无本地内容可留，17-S3）；下拉刷新失败 → Toast；
  收藏写失败 → **行内**（按钮回落原态 + Toast 文案「收藏没保存上，再试一次」），不整屏
- **离线**：有缓存 → 正常显示 + 17-S4 离线横幅；收藏动作**入本地待重放队列**（乐观更新 +
  回滚语义见「待裁决 2」）；无缓存 → 整屏错误态「离线：歌单需要联网获取」
- **未登录 / 游客**：浏览与逐曲试听正常（`GET /api/tracks/:id/preview-url` 匿名可访问）；
  点「收藏」→ 17-S6 游客登录引导 sheet（邮箱登录入口 + 游客继续）；收藏态对游客恒为「未知」→ 显未收藏态，
  不报错
- **Reduce Motion**：头图折叠退化为「直接显隐」（不缩放、不共享元素）；导航条玻璃淡入退化为一帧到位；
  播放钮按压弹跳关闭；列表入场错峰淡入关闭

## 5. 深浅双主题差异

- 页面底 `color.canvas`；列表行 `color.canvas`，无独立卡底
- 头图遮罩与白字：两套主题**同值**（白色文本 + 深色遮罩保证对比），差异只出现在
  遮罩强度（TG-12 需 light/dark 双值）与 A 导航条玻璃（`material.navGlass` 双 mode）
- 操作行按钮：`gradient.brandButton` 双主题共用；次按钮底 `color.surface`、描边 `color.line` 各自双值
- 播放中高亮行底色 `color.accentSoft`（Dark 为深橙衬底），不额外加发光

## 6. 可访问性

- **朗读顺序**：「返回」→ 标题（`type.largeTitle` 作为屏幕标题）→ 元信息
  「24 首，约 1 小时 52 分钟，策划 Cova 编辑部」→ 简介（展开后含隐藏文本，朗读同步）→
  「播放全部，按钮」→「收藏歌单，按钮，已选中/未选中」→ 列表「曲目列表，24 项」→ 每行
  「曲名，艺人，时长，按钮」（整行单元素 + ♡/⋯ 独立元素，见 components §1）
- 头图折叠**不得**把标题从无障碍树里移除（滚出屏幕时保持可聚焦，否则 VoiceOver 用户丢失上下文）
- **Dynamic Type**：AX 档下 B 头图高度不随之放大（比例固定），C/D 文本换 2/5 行、
  操作行两钮改为上下堆叠（各占满宽），列表行高随文本增高（封面 48 固定）
- **触控目标**：返回 / 收藏（导航条）/ 播放全部 / 收藏（操作行）/ 每行播放 / ♡ / ⋯ / 展开简介文字钮
  ≥44pt（文字钮上下扩展热区）

## 7. 数据契约

| 用途 | 端点 | 字段 |
|---|---|---|
| 详情 + 曲目 | `GET /api/playlists/:id` → `{playlist, tracks[]}` | `playlist{id,title,titleCn,description,descriptionCn,cover/coverUrl/coverMedia{…},scene,curator,trackCount,totalDuration}`；`tracks[]` = **普通列表投影** `TrackDto`（api-contracts §2 投影警告：本端点非 similar 投影） |
| 收藏/取消 | `POST` / `DELETE /api/saved-playlists`，body `{playlistId}` | 响应 `{saved, playlistId, action}` |
| 曲目收藏（行内 ♡） | `POST` / `DELETE /api/favorites`，body `{trackId}` | 响应 `{message, favoriteCount}` |
| 播放 | 队列由本地构建（`tracks[]` 的 `audioUrl`）；上报 `POST /api/tracks/play`（`source:"app-ios"`，幂等键，NEEDS-2） | — |

- **NEEDS-9 未解锁**（`GET /api/playlists/:id` 的 `playlist` 缺 `isSaved / writable / disabledReason /
  saveAction`）→ UI 降级（本条为硬性要求，禁止把详情当作有收藏态）：
  1. 进入本屏时收藏态取自 **05/12b 列表缓存的 `isSaved`**（`savedAt` 可作二次排序依据）；
  2. 缓存也无（深链直入）→ 收藏钮显**中性未选态**（书签轮廓），并在首次点击时按「未收藏」发起 POST，
     以响应 `{saved}` 回填真实态；
  3. 页面顶部**不出现**「收藏状态未知」类提示（对用户是噪声）；
  4. 下拉刷新**不得**把已回填的收藏态重置为未知（本地态优先于无字段的详情响应）。
- **可空字段规则**：`curator` 空 → 元信息省略该段（不留分隔点）；`description*` 全空 → D 区不渲染；
  `trackCount` 与 `tracks.count` 不一致时**以 `tracks.count` 为准**（列表是事实源，计数只做首屏占位）；
  `coverMedia` 全空 → 占位块（同 05）
- **分页/刷新**：详情端点无分页参数 → 整表一次返回，本屏不做无限滚动；下拉刷新重取详情；
  从 05 返回时若列表数据已在本地则不重取
- **字段白名单**：本屏不显示 `favoriteCount`、`playCount`（契约有但不利于「顺序优先」的屏焦点）

## 8. 边界与文案

- **截断**：导航条标题单行；头图标题中文优先 2 行；艺人/曲名按 components §1 两行；简介 3 行 + 展开
- **极值**：`tracks` 1 首 → 元信息「1 首」；>200 首 → 分帧渲染 + 到底「已显示全部」；
  含后端已下架曲目（`tracks[]` 里不出现，属后端过滤）→ 计数自然一致，无需前端处理
- **并发冲突**：
  - 连点收藏 → 按钮进入 loading（内嵌菊花），第二次点击被吞；响应回来按最终态渲染
  - 「播放全部」与收藏同时进行 → 互不影响；若正在 SSE/轮询（09）不占用本屏资源
  - 队列替换语义：点行/播放全部 = **替换队列**（components §1），MiniPlayer 随之更新
- **零余额（D12）**：本屏**不出现**下载/购买入口（03 §4 行菜单的「下载」项同样在放行前隐藏）；
  「播放全部」不涉及扣费
- **文案清单**：`播放全部` / `收藏` / `已收藏` / `这个歌单暂时还没有曲目` / `歌单可能刚更新，下拉看看` /
  `返回歌单广场` / `收藏没保存上，再试一次` / `展开` / `已显示全部` / `离线，展示上次内容`

## 9. 验收判据

- [ ] 头图随上滑折叠进导航条，折叠过程无跳帧；Reduce Motion 下退化为直接显隐且功能完整
- [ ] NEEDS-9 未解锁时：从 05 进入收藏态正确回显；深链直入时收藏钮为中性态、点击后由响应回填；
      下拉刷新不重置收藏态
- [ ] 歌单收藏用书签符号、曲目收藏用爱心，全站无混用
- [ ] 空歌单：操作行保留但「播放全部」禁用；无「0 首」播放队列被建立
- [ ] 游客可完整浏览与逐曲试听；点收藏走登录引导 sheet（可取消回本屏）
- [ ] 所有值来自 token；AX5 档下操作行堆叠、无横向溢出
