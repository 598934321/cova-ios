## 3. 区块规格

### A 导航条

- 系统大标题「创作」`type.largeTitle`（页签根屏，无返回钮、无品牌位 —— 04 §2）；
  右端**不放**搜索钮（搜索 v1.0 不做，见「待裁决 4」）
- 若从通知深链返回后进入本屏，标题右侧显一次性「未读」提示点（`color.accent`，8pt 档 TG-18），
  进入任一会话即清

### B 新会话主操作

- 主按钮：高 50（TG-07）、`radius.capsule`、`gradient.brandButton` + 白字 +
  `elevation.primaryButtonShadow`；图标 `sparkles`；宽 = 屏宽 − 2×`spacing.pageGutter`
- 与首条会话行间距 `spacing.lg`；吸顶常驻（不随列表滚走，玻璃底）
- 禁用态（未拿到建会话能力时）：`color.muted` 底（components §10）

### C 会话行（SessionRow）

- 容器：整行一个主点击目标；左右 `spacing.pageGutter`；上下内边距 `spacing.md`；最小高 64
  （与 TrackRow 同级，TG-19 行高档）
- 左：封面 48 方（圆角 `radius.control`），源为会话首个生成候选封面；无 → `color.surface` 底 +
  `sparkles` 符号（`color.accentText`）
- 文本栈（间距 `spacing.xs`）：
  - 标题：`type.headline` / `color.fg`，1 行截断
  - 摘要：`type.subhead` / `color.secondary`，**1 行**（本屏空间预算不给 2 行），
    超长按 §8 截断
  - 时间：`type.caption` / `color.muted`（相对时间，规则见 §8）
- 右：状态区（进行中进度环 / ⋯ 菜单），二者可同现（进度环在 ⋯ 左）
  - 进度环：直径 20（TG-18 图标/环尺寸档），轨道 `color.line`、进度 `color.accent`、
    线宽 2（TG-04）；环内不放百分数（空间不足），百分比走 VoiceOver 标签
  - ⋯ 菜单：图标按钮 ≥44pt 热区（TG-03）→ 「重命名」「删除」（放行状态见 §7）
- 行间分隔：`color.lineSubtle` 1pt（TG-04），首行不加
- 进行中行的整行左侧另加 2pt `color.accent` 竖条（与 components §7 选中指示条同规格，
  语义 = 有任务在跑），**不**用底色高亮（底色高亮留给「当前所在会话」返回时的一次性高亮，
  `motion.duration.instant` 淡出）

### E 左滑动作

- 露出宽度 = 单枚 destructive 钮宽（`spacing.xxl`×2 预算，TG-20 滑动动作几何），
  底 `color.error`，白色 `trash` 图标 + 「删除」
- 滑开后再点行 = 先收起不误触；松手未达阈值 → 弹回（`motion.curve` + `duration.normal`）

## 4. 状态变体

- **加载（首访）**：B 主钮立即渲染（导航不阻塞）；列表 5 行骨架 = 48 方快 + 两条文本条 +
  一小条（时间位），`color.surface` 呼吸（17-S1）。**不骨架进度环**
- **加载（下拉刷新）**：保留旧行 + 系统刷新控件（accent 着色，01 §8 同规则）
- **空态（重要）**：登录后 0 会话 → 17-S2 规范：插画位 + 「还没有你的创作」(`type.headline`/`color.fg`) +
  「一句话就能开始：说场景、说情绪、说时长」(`type.callout`/`color.secondary`) +
  **3 枚 prompt starter chips**（`../components.md` §6 语汇，`color.surface` 底 +
  `color.secondary` 字，可点）+ 主 CTA 胶囊「开始新会话」→ B 同动作。
  starter 文案为本地常量（无端点），示例见 §8 文案清单
- **错误**：首载失败 → 整屏错误态（17-S3：无可留内容）error 图标 + 「会话列表没取到」+
  「重试」主钮；刷新失败 → Toast；**401 且 single-flight refresh 失败** → 回落未登录：
  页签栈回根 + 本页签根区换 17-S6 引导形态 + 一次性 Toast「登录状态已过期，请重新登录」
- **离线**：有本地缓存（按 owner 绑定，D9）→ 正常列表 + 17-S4 离线横幅「离线，展示上次内容」；
  「新会话」钮禁用（建会话是写操作，离线不可发）；无缓存 → 整屏错误态「离线：创作需要联网」
- **未登录**：本屏不呈现（见 §1 门槛）。若他端登出导致会话失效 → 按错误态最后一条处理
- **Reduce Motion**：行入场错峰淡入关闭；进度环旋转（无限）→ **退化为静态环 + 一次性 2pt 高的
  不确定进度条**（`color.accent`），文字「生成中」常驻；左滑弹回动画退化为一帧到位；
  一次性高亮淡出退化为一帧显、一帧消

## 5. 深浅双主题差异

- 全走 `color.*` 双 mode：底 `color.canvas`、行内符号/文字三级（fg/secondary/muted）、
  分隔 `color.lineSubtle`、骨架 `color.surface`
- Dark 下 destructive 钮 `color.error` 与白图标对比度已达标（tokens 双值同色，不需本屏调整）
- 进行中 2pt 竖条与进度环 `color.accent` 双主题同值（accent 是唯一不分主题的品牌值）
- 导航条玻璃 `material.navGlass` 双 mode

## 6. 可访问性

- **朗读顺序**：「创作，标题」→ 「新会话，按钮」→「会话列表，N 项」→ 每行**单元素**复合标签：
  「<标题>，<摘要>，<相对时间>，<有任务时：生成中，约 68%>，按钮」，行内 ⋯ 作为**第二个**元素
  「更多操作，<标题>」；左滑动作在元素序列中紧随该行（「删除，破坏性操作，按钮」）
- 进度环不设独立可聚焦元素（数值并入行标签），避免 VoiceOver 在旋转动画上重复播报
- **Dynamic Type**：AX 档下摘要改为**最多 2 行**、时间移到标题行右端（避免行高三重叠加）；
  封面 48 → 由行高撑开，缩至 `spacing.xxl`+`spacing.lg` 档（TG-19 联动）；B 主钮保持满宽单行；
  左滑动作宽度增大以容纳文字
- **触控目标**：新会话钮 / 整行 / ⋯ / 每枚 starter chip / 删除钮 / 重试钮 ≥44pt
- 破坏性操作（删除）在 VoiceOver 下必须先听到二次确认 Dialog 的标题（17-S7 焦点接管）

## 7. 数据契约

| 用途 | 端点 | 说明 |
|---|---|---|
| 列表 | `GET /api/find-my-song/sessions` | api-contracts §4 记录该端点存在（需 Bearer），但**未逐字段列举响应** |
| 详情 | `GET /api/find-my-song/sessions/:id` | 含 `messages / generationJobs`（§4）→ 仅 09 消费 |
| 建会话 | `POST /api/find-my-song/sessions`，body `{workflowMode:'one-step', skipWelcome:true}` | v1.0 恒一步模式（PRD 4.4），CovaCore 已有请求 DTO |
| 删除 | **未文档化** | 见下 |

- **行的字段依赖与降级（本屏最大风险，逐条钉死）**：
  | 行元素 | 需要的语义 | 契约状态 | UI 降级（拿不到时） |
  |---|---|---|---|
  | 会话标题 | 一行的可辨识名称 | 实测：`title`（默认服务端缺省值 `新会话`，不等于"用户起过名"）+ `titleCn` + `proposedTitle`（agent 提议、待确认）+ `lastMessage` | 兜底链：`titleCn` → `title`（**`新会话` 按没给处理**）→ `proposedTitle` → `lastMessage` 前 20 字 + 「…」→ 「未命名会话」（`color.secondary`）。不猜时间戳当标题（2026-10-01 C6 修订：服务端缺省值不再原样上屏，曾导致整列全叫「新会话」） |
  | 最后消息摘要 | 列表可扫读 | **未文档化** | 该行第二文本条不渲染，标题与时间上移补位 |
  | 时间 | 排序与相对显示 | **未文档化** | 整条不渲染（不显示「—」噪声） |
  | 首个候选封面 | 视觉锚点 | **未文档化** | 落 `sparkles` 符号占位（§3.C） |
  | 进行中任务与进度 | 进度环 | **列表响应不含 `generationJobs`**（§4 明确「含」的是详情） | 用**本设备内存中未终态的 job**（由 09 发起者持有）绘制进度环；冷启动后不显——**不得**为列表逐行发详情请求（N+1），也不得造字段 |
- 上述「未文档化」项 → 建议登记 `docs/NEEDS.md`（候选编号 `SESSION-LIST-FIELDS`，
  要求：会话列表响应带 `title / lastMessage / updatedAt / firstCoverUrl / activeJobSummary`）。
  **CovaCore 目前未建模会话列表 DTO**（G3 未覆盖 M2），实现时先补 DTO 再施工 UI。
- **删除**：`inventory.md` 行 08 要求左滑删除，但 `docs/api-contracts.md` §4 **未记录删除端点** →
  放行前：左滑手势不启用、⋯ 菜单不含删除项（整项不渲染，非禁用）。解锁后走二次确认（17-S7）。
  登记「待裁决 2」，**不得凭推测调用未文档化端点**。
- **分页/刷新**：§4 未记录 `page/limit` 参数 → v1.0 取响应全量并按时间倒序，
  到底显「已显示全部」；下拉刷新重取；进入本屏不自动重取（缓存 ≤ 5min，TG-09）
- **可空规则**：任何字段可空 → 按上表降级；行永远可点（`id` 是唯一必需字段）

## 8. 边界与文案

- **截断**：标题 1 行、摘要 1 行（AX 档 2 行），中文按字、英文按词截断（TG-17）
- **相对时间**：<60s「刚刚」；<60min「N 分钟前」；今天内「N 小时前」；昨天「昨天」；
  本周内「N 天前」；更早「M月D日」；跨年「YYYY年M月D日」；一律不用 12/24 小时歧义格式
- **零结果**：空态见 §4；仅有 1 条会话时不显示分组标题
- **极值**：>50 条 → 分帧渲染；同秒并存的会话以 `id` 稳定次序兜底（不抖动）
- **并发冲突**：
  - 删除进行中该会话正在 09 被写（SSE/轮询）→ 本屏不允许同时打开两处；从 09 返回后才可左滑
  - 列表刷新与「新会话」并发 → 建会话成功即把新行插到首位（不等刷新），且**不**重复创建
    （按钮点击后进入 loading，成功/失败前不可再点）
  - 他端删除了本端缓存的会话 → 点进 09 返回 404 → 09 整屏错误态「这个会话已经不在了」，
    返回后本屏静默移除该行
- **零余额 / D12**：本屏不出现余额、扣费、充值任何文案；进度环不预告费用
- **prompt starter 常量（≤3 枚，中文）**：`做一首夏日广告配乐，30 秒，轻快` /
  `来一段适合深夜写作的纯音乐` / `给短视频做一首中国风 BGM`
- **文案清单**：`创作` / `新会话` / `未命名会话` / `生成中` / `已显示全部` / `还没有你的创作` /
  `一句话就能开始：说场景、说情绪、说时长` / `开始新会话` / `会话列表没取到` / `重试` /
  `离线，展示上次内容` / `离线：创作需要联网` / `登录状态已过期，请重新登录` /
  `删除` / `确定删除这个会话？` / `这个会话已经不在了`

## 9. 验收判据

- [ ] 游客从任何入口点「创作」都先遇到登录引导，取消后回到原屏原滚动位置，本屏未被渲染
- [ ] 「新会话」连点只创建一个会话（日志/网络面板仅一次 POST），成功后首位插入并进 09
- [ ] 未解锁期：列表**不发**逐行详情请求（网络面板确认）；无 `generationJobs` 字段时进度环
      只出现在本机发起且未终态的行上，冷启动后消失且无报错
- [ ] 左滑删除在删除端点未文档化时**完全不存在**（手势、菜单项、VoiceOver 元素三处皆无）
- [ ] 空态含 3 枚可点 starter + 主 CTA，点 starter 能进入 09 且输入框已带该文案
- [ ] AX5 档下行不溢出、摘要 2 行、时间换到标题行；进度环对 Reduce Motion 用户为静态替代
- [ ] 全部值来自 token（抽查进度环线宽、行内边距、胶囊高度）
