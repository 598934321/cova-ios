## 3. 区块规格与状态变体 · S1 加载（骨架屏规范）

| 项 | 规格 |
|---|---|
| 色 | 块底 `color.surface`；**禁止**自造灰值或使用 `color.line` |
| 呼吸 | 周期 1.2s（`../components.md` §8 钉死；tokens 无该时长档 → 缺口 TG-41），幅度：不透明度峰值差 ≤12%（TG-42） |
| 形状 | **严格跟随真实布局**：块的宽/高/圆角与它要替换的元素的 token 完全一致（封面块用 `radius.control`、卡块用 `radius.card`） |
| 族 | ① 行骨架（列表用，行数：TrackRow 屏 8 行 / PlaylistRow 屏 4 行 / SessionRow 屏 5 行）② 卡轮廓（计划卡、候选卡组、空间卡：整卡 1pt `color.line` 描边 + `color.surface` 轻底，**不**呼吸）③ 文本条（3 种长度档，TG-06：长 = 100%、中 = 65%、短 = 40%，垂直圆角 `radius.capsule`）④ 控件骨架（胶囊/按钮按真实尺寸）⑤ 等待指示 |
| 数量上限 | 单屏骨架块 >12 个即视为「用骨架盖住布局不确定性」→ 评审打回，改为分区独立加载 |
| 不做的事 | **不**做 shimmer 高光扫过（与 Cova 克制基调冲突，且低值机型掉帧）；**不**做「骨架 → 内容」的交叉淡出超过 `motion.duration.fast`；**不**骨架进度环、不骨架本屏可能不存在的可选区（12c §4 先例） |

## 4. 区块规格与状态变体 · S2 空态规范

- 结构（自上而下，居中）：**插画位**（120×120，TG-43 插画档；容器 `color.surface`，
  v1.0 若插画未定稿 → 用 `color.line` 描边的空框，**不**放 emoji/字符画）→
  **标题** `type.headline` / `color.fg`（≤10 字，一句话说清「这里会有什么」）→
  **引导文** `type.callout` / `color.secondary`（≤2 行，说清「怎么让它有」）→
  **主 CTA**（胶囊 50，TG-07；`gradient.brandButton` 仅用于**产品主线**空态，
  如 08/12c「开始新会话」；次要空态用次按钮样式）→ **可选次动作**（文字钮 `color.accentText`）
- 变体：
  - **带 starter chips**（08/12c 空态）：chips 位于引导文与主 CTA 之间，
    `../components.md` §6 规格，≤3 枚
  - **带筛选清除**（03 无结果）：主 CTA 替换为「清除全部条件」（次按钮样式），**不**显示插画位
    大框（筛选无结果是高频态，插画会放大挫败感）
  - **无插画位**（sheet/半屏容器内，如 07 相似区）：整区隐藏优先；必须显示时用「一行文本 + 文字钮」
- 禁令：空态**不得**出现「暂无数据 / No data / 空空如也」类工程话术；
  **不得**用空态掩盖错误（错误必须走 S3）；**不得**在空态里放购买/充值引导（D12）

## 5. 区块规格与状态变体 · S3 错误规范（形态 + 判定表）

**四形态**（01–16 的规格里出现的「Toast/行内/整屏」在本表统一定义；07 提出的
「sheet 内整块替换」正式登记为 ③）：

| 形态 | 规格 | 用于 |
|---|---|---|
| ① **Toast** | `../components.md` §8：顶部下滑胶囊、`color.elevated` 底、状态色 icon（`color.error`/`color.warning`/`color.success`）、`type.callout` / `color.fg`，3s 自动消失（TG-41 同族时长档未入库），z 序 `elevation.zOrder` toast 层；同一时刻仅一条，后到替换并重置计时 | 非阻塞的**后台动作**失败：分页、下拉刷新、播放切歌、收藏（有行内回落时并行） |
| ② **行内** | 贴着可归因元素：错误文本 `type.subhead` / `color.error` + 符号（TG-18）；表单类另加 1pt `color.error` 描边（10 §3） | 用户能从**原位重试**且上下文必须保留：登录字段、卡片内费用行（余额不足）、下载单行、候选校验失败 |
| ③ **区块内**（sheet/卡内整块替换） | 容器内替换 1pt `color.line` 描边块：error 符号 + `type.headline` 标题 + `type.callout` 说明 + 主/次钮（≥44pt） | 半屏/卡片容器内的整块内容不可用（07 曲目详情、09 单张计划卡拉取失败）——不能塞整屏、不该只 Toast |
| ④ **整屏** | 页面级：error 符号/插画位 + `type.headline`「XX 没取到」+ `type.callout` 原因 + 主钮「重试」（次钮视屏而定） | **首载失败且无本地内容可留**（05/06/07 无缓存/08/11/16） |

**判定表（评审可对着它判真伪）**：

1. 有本地内容可留？ → 否 → **④**；是 → 继续
2. 错误可归因到某个字段/行/卡？ → 是 → **②**；否 → 继续
3. 失败的是「可选/加分区块」？ → 是 → **静默隐藏该区块**（不提示，12c §4 / 07 §4 先例）
4. 失败的是「用户当前正等待的结果」？ → 是 → **③**（在容器内）或 **④**（在全屏）
5. 失败的是「用户没在等的后台动作」？ → 是 → **①**
6. 抽屉/导航/设置类容器 → 一律不整屏、不 Toast（04 §4 先例），只做行内「未同步」

- 通用禁令：错误文案**不出现**技术词（HTTP 码、JSON、schema、超时、`decode`）；
  **不出现**英文态名；重试钮文案统一「重试」（不「再试一次/刷新」混用）；
  401 类会话错误由全局会话层处理（17-S6 + 08 §4），各屏**不**各自弹登录框

## 6. 区块规格与状态变体 · S4 离线 / S5 Reduce Motion

**S4 离线（两种密度）**

- **细条**（sheet/卡内，如 07/09）：`color.warning` 1pt 描边 + `color.accentSoft` 底
  （warningSoft 缺档 TG-21），`type.subhead` / `color.fg`，常驻至网络恢复
- **横幅**（全屏列表顶，如 05/06/08/11/12x/16）：同配色，高 = 文本 + 上下 `spacing.md`，
  占导航条之下、内容之上，不随滚动消失
- 文案统一：`离线，展示上次内容` / `离线：<该屏关键资源>需要联网` / `离线，下载已暂停`
- 离线时**必须**保留：本地文件播放（12d）、只读浏览（13/14/15）、主题与清缓存（15）；
  **必须**禁用：任何写操作与建会话（08 §4）

**S5 Reduce Motion 退化矩阵**（全局唯一源；各屏 §4 只列命中项，不重述规则）

| 动效（tokens 锚点） | 正常态 | Reduce Motion 替代态 |
|---|---|---|
| 屏/抽屉转场（`motion.duration.page` + `motion.curve`） | 弹簧位移 | 直接呈现（无位移、无淡入） |
| push/present（`motion.duration.slow`/`normal`） | 位移动画 | 一帧到位 |
| 卡片入场错峰淡入（`duration.normal`，延迟 40ms/区） | 逐区淡入 | 一次性呈现 |
| 骨架呼吸（1.2s，TG-41） | 透明度呼吸 | **静止 `color.surface` 色块** |
| 封面像素呼吸（09/02 生成中） | 像素格明灭 | 静止像素格 + 「生成中」文字徽标（`color.warning`） |
| 进度环旋转（09 候选 / 08 行） | 无限旋转 | 静态环 + 不确定进度条（2pt，`color.accent`）+ 文字百分比 |
| 音量 symbol 动画（components §1 / 02 §6） | `.variableValue` | 静态符号 |
| 播放/暂停 `.symbolEffect` 内容过渡 | 形变 | 一帧切换 |
| 打字机式逐 token 追加（09） | 流式追加 | 整段一次呈现 |
| 主色铺底/背景交叉淡入（02，`duration.hero`） | 交叉淡入 | 直接替换 |
| 缩放弹跳（收藏 ♡，`duration.fast`） | 弹跳 | 一帧换色 |
| 头图折叠/共享元素（06/02） | 连续形变 | 直接显隐 |
| Toast 下滑 | 位移 + 淡入 | 一帧显 / 一帧消（仍 3s 消失） |
| Dialog 出现（`duration.fast`） | 缩放淡入 | 一帧到位（焦点接管不变，S7） |
| 数字滚动（04/11 余额） | 滚动 | 直接显新值 |
| 菊花（等待指示） | 系统旋转 | **保留**（功能性指示，非装饰；系统会自行降速） |

> 原则（`motion.reduceMotion` 原文）：**装饰性**动效全部要有替代态；**指示性**动效（菊花、
> 进度值）不得为了 Reduce Motion 而丢失信息。

## 7. 区块规格与状态变体 · S6 游客引导 / S7 模态与焦点 / S8 进度与等待 / S9 同构列表页

**S6 游客登录引导（受限动作的统一出口）**

- 触发：游客点击 ♡ / 加入队列 / 收藏歌单 / 创作 / 我的资产 / 我的
- 形态：**底部弹起 sheet**（`color.elevated` + 顶部 `radius.hero`，高 = 内容 + 安全区，
  不超过屏高 45%，TG-15）：标题 `type.headline`「登录后就能…」→ 说明 `type.callout` /
  `color.secondary`（一句，说清**这一件**能做什么，不泛化）→ 主钮「邮箱登录」→ 10
  → 文字钮「先逛逛」（= 关闭并保持游客态）
- 记录被拦截的意图（登录 intent，D5 CAS）：登录成功后**重放一次**（10 §7）
- 禁令：同一动作**不重复弹**（用户刚关掉又点同一处，本会话内不再弹，改为行内
  `type.caption`/`color.muted`「登录后可以用」）；**不得**用 Dialog（阻断感过重）

**S7 模态与焦点（Dialog）**

- 规格：`../components.md` §8（居中 `color.elevated`、`radius.card`、标题 + 正文 + 主/次按钮）；
  destructive 主钮 `color.error` 底 + 白字；排版档缺口 TG-39
- 焦点：出现时 VoiceOver 焦点进标题、转子限制在 Dialog 内、关闭后**归还触发元素**
- 硬要求：需二次确认的动作 = 登出（15 §3.H）、账号删除（15 §3.G）、批量删除/取消收藏
  （12a §3 多选态）；**不需要**确认 = 单条可逆动作（06/12b 取消收藏、07 加入队列）
- Dialog 期间底层内容不可交互、不发请求（15 §8）

**S8 进度与等待**

- 确定进度：条（高 4，TG-23，轨道 `color.surface` / 填充 `color.accent`）+ `type.mono` 百分比；
  用于 09 交付进度、12d 下载
- 不确定等待：菊花（`color.accent`，仅用于「按钮内」与「封面位」，09/12d/02 §9）
- 阶段进度（09 thinking/run_*）：不用百分比，用短语 + 符号（映射表在 09 §3.F，唯一源）
- 禁令：同一区域**不得**同时出现条 + 环 + 菊花三件（最多两件，且一为文字短语）；
  进度数字变化**不**自动播报（09 §7 / 12d §6）；等待 >10s 必须出现「停止」出口（09 §4.2 触发 1）

**S9 同构列表页（04/11 下挂的四屏）**

- 骨架基线唯一源：`12a-favorites.md` §2–§6（A 导航条 / B 摘要行 / C 主体 / D 尾部状态行 /
  E 左滑动作 / 多选态）
- 各屏只写差异：12b（PlaylistRow + `savedAt` 排序）、12c（只读总览，无写入口）、
  12d（空间卡 + 下载状态机 + D12 三门）
- 统一规则：行内标签胶囊在收藏/已下载页**不显示**（06 先例）；本地态共享使「别处取消收藏 → 回屏即消失」
  成立（12a §8）；`title*` 全空的条目**静默不渲染**（12a/12b/16 一致）

- **引用协议（谁钉什么，单向，禁止双向复制）**：
  | 事实 | 唯一源 |
  |---|---|
  | 态的形态与判定 | 本页 S1–S9 |

  | Token 缺口全集 | 本页 §12 |
- **与其它屏的契约冲突处理**：若某屏的态与本页冲突，以本页为准并回改该屏；

## 10. 边界与文案（全局禁令与统一措辞）

各屏 §边界与文案 只写屏专属内容；下列为**全局**约束，任何屏不得另立口径：

- **统一措辞**：`重试`（不「再试一次/刷新/重新加载」混用）/ `已显示全部` / `未同步` /
  `离线，展示上次内容` / `登录后可以用` / `支持` / `不支持` / `加载中…`
- **禁止技术词外露**：HTTP 码、JSON、schema、decode、超时、SSE、轮询、generation、
  `run_*`、payload、`Bearer`、任何态的英文枚举名（`ready/generating/demos_ready` 等）
- **禁止承诺不存在的能力**（无契约即不做，也不写文案）：断点续传、跨设备恢复、云端同步、
  逐行时间轴歌词（D15）、实时推送（NEEDS-7）、多码率音质（15 待裁决 5）、
  个人歌单创建/加入、关注/粉丝/评论/社交（PRD 4.4）
- **D12 合规禁词（全局，不只 13/14）**：`购买` `充值` `支付` `价格` `¥` `元/月` `立即开通`
  `升级` `订阅管理` `付款` `恢复购买` `限时` `优惠`；余额只允许「展示」，
  且**永不**把「余额为 0 / 取不到」渲染成错误色或催促话术（11 §8、09 §10）
- **凭证与地址**：token / 签名 URL / `audioUrl` / `audioDownloadUrl` 不显示、不写日志、
  不入持久化、不入通知（AGENTS 硬边界 3、TD-23）
- **截断通则**：中文优先 2 行（列表主标题类 1 行），英文按词、中文按字，尾部 `…`；
  邮箱/URL/编号类**不截断**，改为降字号或换行（10/11/14/16）
- **数字通则**：一律 `type.mono` + tabular-nums（`type.note`）；时间折算口径
  「≥60 分显小时+分钟」；相对时间口径见 `08-ai-sessions.md` §8（唯一源）
- **极值通则**：长列表分帧渲染 + 到底「已显示全部」；`title*` 全空的条目静默不渲染（12a/12b/16 一致）
- **并发通则**：写按钮提交期间进入 loading 并吞后到点击；乐观更新必须有回滚；
  同一资源的两处写入口径只能有一条（12c §3.A 先例）
