# 15 · 设置

> G2 逐屏规格。基准 393×852pt。要点源：`inventory.md` 行 15。
> 数据源：`GET /api/auth/me`（能力位）、`POST /api/auth/logout`（写操作）、
> `DELETE /api/auth/account` + `POST /api/auth/account/delete/cancel`（删号，§7 #4 未上线）、
> 本地偏好（D9 owner 绑定）。通用态规范源：`17-state-gallery.md`；
> Dialog 规范源：`../components.md` §8。

## 1. 屏与上下文

- **层级**：push 自 11「设置」行；入「我的」页签的导航栈（04 §3）。
- **入口**：① 11「设置」行；② 深链 `settings`。
- **互链**：主题/网络偏好即改即生效（不回上屏）；「清除缓存」在本屏内完成并回写占用数字；
  「通知」跳系统设置；三个外链 → Safari；「登出」→ Dialog（§3.H，页面最末行）；
  「注销账号」→ App 内两步（后果 Dialog → `POST /api/auth/delete-account`，§3.G）。
- **返回**：退栈回 11。
- **登录门槛**：**无**。游客也要能改主题、清缓存、看隐私条款（Apple 对隐私政策入口是强制的）。
  账号区（登出/注销账号）只在已登录时渲染。

## 3. 区块规格

- **A 大标题**：系统 `largeTitle`（不再手写 `material.navGlass` 叠层）
- **分组标题**：`insetGrouped` 组头（系统字级，`color.muted` 语义等价），组间留白随系统
- **设置行（B–I 通用几何）**：原生 inset 行（系统行高 ≥44pt，TG-19）；
  左标签 `type.headline` / `color.fg`（1 行），右值 `type.subhead` / `color.secondary`
  （数字 `type.mono`），尾符号 `chevron.right` / `color.muted`；
  行间分隔由系统 inset 样式承担（不再自绘 `color.lineSubtle` 1pt）
- **B 主题**：值为三选 → 点击展开 sheet（`color.elevated`，`radius.card`，
  三行单选，选中 `color.selected` + 左侧 2pt `color.selected` 指示条（web v2.65.0
  去橙化选中档，design/README「与 web 的统一设计语言」）。选项 = 「跟随系统 / 浅 / 深」，
  **与 `CovaUI.CovaThemeMode{system,light,dark}` 一一对应**
  （三值枚举已存在，UI 不得造第四项）
- **C 只连 Wi‑Fi 下载**：胶囊开关（TG-35，与 12d §3.C 同一份偏好键，双向同步）；
  **门 1（D12）未放行时整行不渲染**（它属于下载功能面，不单独留在设置里）
- **C′**：不新增技术行。播放上报（`POST /api/tracks/play`，`source:"app-ios"`）是行为事实，
  **不**作为设置项暴露，也**不**在此写「上报」字样（用户语汇里那是隐私噪声）；
  隐私政策外链承载该说明
- **D 清除缓存**：右侧值为当前缓存占用（本机计算，`type.mono`）；点击 → Dialog（§3.H 形态）：
  标题「清除缓存？」正文「会清除封面与试听缓存，不影响已下载的音乐与登录状态。」
  主钮「清除」（`color.fg` 底 `color.accentSoft`？→ 否：主钮用 `gradient.brandButton` 会把
  清除动作抬成主动作，故次按钮样式 + 文字 `color.fg`）；次钮同 §3.G②（iOS 26 取消钮不渲染，
  关闭走点外/下滑）
- **E 生成完成通知**：右值 = 系统授权态回显（「已开启 / 已关闭 / 未设置」）；点击 →
  跳系统设置（`UIApplication.openSettingsURLString`）。**App 内不自建通知开关**
  （授权由系统管理，自建会产生「App 里关着、系统里开着」的双源真相）。
  NEEDS-7 未就绪 → 本行为**必须存在**（本地通知兜底的可控出口，见 §7）
- **F 外链三行**：尾符号统一 `arrow.up.right.square`（`color.muted`）；目标为常量 URL，
  不拼用户数据；版权说明 → `covalink.cn/licensing`（PLAN §2 风险表钉的路径）
- **G 注销账号（App 内流程；端点已上线 = web v2.65.0 `POST /api/auth/delete-account`，
  2026-10-02 对齐）**：仅已登录渲染。两步式——端点无请求体、立即生效、吊销全部会话，
  **服务端不收密码**（无凭据复核位）、**没有冷静期与撤销端点** ⇒ 复核与受理态全部不存在，
  客户端不发明：
  - **① 行**：标签「注销账号」`color.error`（命名与 web 设置页同词；该操作是注销并匿名化，
    不是物理删除记录——「删除」是骗用户的说法）；常态右值空 + chevron。
  - **② 后果 Dialog**（同 §3.H 形态，`•` 逐条；如实描述**立即生效、不可撤销**）：
    「注销后账号立即退出，邮箱、手机号和第三方登录都会解除」
    「授权订单与创作记录按法律要求保留，但不再关联可识别的个人信息」
    「正在播的音乐会停止，播放队列会清空」「离线记录与缓存将按账号清除」；
    主钮「确认注销」（destructive）/ 次钮：iOS 26 起 `confirmationDialog` **不再渲染**
    `role:.cancel` 钮（系统行为，实测 AX 树 0 命中）——关闭通道是「点 Dialog 之外」或下滑；
    规格不再写死「取消」次钮，实现里显式声明的 cancel 钮是死代码、已随本批移除。
  - **③ 回执分流**：`POST /api/auth/delete-account`，**无请求体**
    （端点不读体；重复提交天然幂等——再发只会撞 401，不会产生第二次语义）；
    · 2xx `{ok:true}` → **生效态**：立即走 §3.H 登出链路，Toast 改「账号已注销」；
    · 401（`请先登录`）→ 会话已过期的实话：**不落账号已注销**，只说「登录状态已过期」
      + 本地登出（凭据已死，本机没理由挂着半登录态；若其实是注销落地了，
      用户再登也会失败——屏上不撒「删了」这个自己证不了的话）；
    · 4xx 其他 → Toast 透传服务端 `error`（含「注销失败」兜底）；
    · 404/501 → 「注销服务暂未上线，请联系客服」（回退缺口档，不假装能删）；
    · 5xx/传输失败 → 「注销没成功，请稍后重试」Toast（重试安全）。
- **H 登出（本屏最重要的一处交互）**：
  - 行：标签「登出」`color.error`（整行文字 error 色 = destructive 语义），无尾符号；
    整行 ≥44pt
  - 点击 → **二次确认 Dialog**（`../components.md` §8：居中 `color.elevated` 卡、`radius.card`、
    标题 + 正文 + 主/次按钮，destructive 主钮 `color.error` 底 + 白字）
  - **正文必须把 D8 的四条副作用逐条告知**（一行一条，`type.callout` / `color.secondary`，
    符号 `•`；不得只用「登出后将清除本地数据」这种含糊句）：
    1. 「退出这台设备上的账号」（对应推进会话 generation：本机所有在途请求按代次作废，D8/D5）
    2. 「正在播的音乐会停止，播放队列会清空」（清队列 + 销毁播放器）
    3. 「AI 生成的试听音频与封面缓存会被删除」（清私有音频与封面缓存；
       若 12d 待裁决 2 采纳「保留下载件」，此处须同时写明「已下载的歌曲也会一并删除」）
    4. 「离线记录（搜索历史、缓存的列表与偏好）将按账号清除」（D9 owner 绑定持久化）
  - 主钮「登出」（`color.error`）/ 次钮：同 §3.G②，iOS 26 不给 confirmationDialog
    渲「取消」钮，关闭走点外/下滑；Dialog 期间不发请求；确认后
    `POST /api/auth/logout` → 无论服务端结果如何都完成本地清理（避免他端已挂时用户被卡住），
    失败仅一次性 Toast「服务器登出未确认，本机已退出」
  - 登出完成 → 四个页签栈全部回根、selection 回首页（04 §6），「我的」页签回落游客形态
- **I 关于**：版本行只读（值 = `CFBundleShortVersionString (CFBundleVersion)`）；
  **I′ 开源许可**：本仓零第三方依赖（D3 白名单为空）→ 整行不渲染；
  一旦白名单非空必须出现（Apple 许可合规），规则写在此处以免届时遗漏

## 4. 状态变体

- **加载**：本屏为本地态优先 → **无骨架**。唯一异步值（缓存占用）计算期右位显 `--`，
  完成即回填；`me`（E/G/H 的登录态判定）取本地会话状态，不为此屏发请求
- **空态**：不适用。游客态 = 隐藏 G/H（整段不渲染，含分组标题）
- **错误**：
  - 清缓存失败（占用中文件被占用）→ Toast「有些缓存正在使用，稍后再清」+ 保留原值
  - 登出服务端失败 → Toast（见 §3.H，不阻塞）
  - 跳系统设置/打开外链失败（无邮件/无浏览器可开）→ 由系统处理，App 内不提示
  - **整屏错误态在本屏不存在**（无网络首载内容）——这是设计意图，评审不必找它
- **离线**：全部可用，除 G/H（需请求；H 离线时仍执行本地清理 + Toast 同上；
  G 离线时注销提交发出不去 → 「注销没成功，请稍后重试」Toast，不报假成功）
- **未登录 / 游客**：可见 B/C/D/E/F/I，隐藏 G/H；顶部**不出现**「登录」引导行
  （登录引导属于 04/10，不属于设置）
- **Reduce Motion**：Dialog 出现（`motion.duration.fast` + `motion.curve`）→ 一帧显隐；
  主题切换时的全局色彩过渡（若有）→ 立即生效；sheet 弹起退化为一帧；
  清缓存后进度的百分比刷新无动画

## 5. 深浅双主题差异

- 本屏是「主题切换」的**发生地**：切换即整套 `color.*` mode 换值，无本屏专属色
- 行底 `color.canvas`、Dialog `color.elevated`、分隔 `color.lineSubtle`
- destructive 行与主钮用 `color.error`（双主题同值，Dark 下对比仍达标）
- 「跟随系统」态下本屏外观由 `colorScheme` 驱动，不做「App 内记住上次主题」的隐藏偏好（第四态禁止）

## 6. 可访问性

- **朗读顺序**：「设置，标题」→ 返回 → 每组：组标题 → 每行
  「主题，跟随系统，按钮」/「只连 Wi‑Fi 下载，开关，关闭」/「清除缓存，128 MB，按钮」/
  「生成完成通知，已开启，按钮」/「隐私政策，链接，将在系统浏览器中打开」/
  「登出，破坏性操作，按钮」→「版本 0.2.24，第 35 版」
- **Dialog 焦点接管**（登出、清缓存、注销账号三处）：出现时 VoiceOver 焦点进入标题，
  转子限于 Dialog 内，关闭后焦点**归还「登出」行**；正文四条副作用必须完整朗读
  （不得因长度被截断——这是合规告知，不是装饰文案）
- 开关类行必须有 `value`（开/关），不能用颜色单独表达；主题三选在 sheet 中为
  「单选按钮组」语义（选中项带「已选中」）
- **Dynamic Type**：AX 档下右值移到标签下方第二行（同 11 §6 E 行规则）；
  登出 Dialog 正文四条各允许 3 行；外链行 URL 文字不截断
- **触控目标 ≥44pt**：返回 / 每一行 / Dialog 两钮 / 主题 sheet 三行

## 7. 数据契约

| 用途 | 来源 | 说明 |
|---|---|---|
| 登录态判定（G/H 是否渲染） | 本地 `AuthSession`（signed-out/guest/authenticated，api-contracts §1） | 不为渲染本屏而发 `me` |
| `canUseCovaAI / canDownload` | `GET /api/auth/me` → `entitlements` | 本屏**不**显示能力位（避免与 13 表重复且易口径不一） |
| 登出 | `POST /api/auth/logout` | 失败不回滚本地清理；token 已从 Keychain 移除即视为登出 |
| 主题 | 本地偏好（owner 无关，设备级） | 三值枚举 = `CovaThemeMode` |
| Wi‑Fi 仅下载 / 搜索历史 / 缓存 | 本地（D9 owner 绑定） | 占用数 = `FileManager` 计算 |
| 注销账号 | `POST /api/auth/delete-account`（**已上线**，web v2.65.0） | 无请求体；2xx → 生效（吊销全部会话）；401 → 会话已过期；404/501 → 「暂未上线」档 |
| 外链 ×3 | 常量 URL（Safari） | `covalink.cn/...`；不拼用户参数 |
| 通知授权态 | 系统 `UNUserNotificationCenter` 授权状态 | 只读回显，跳转系统设置 |

- **NEEDS-7 未就绪**（远程推送 token 注册端点缺）→ v1.0 用**本地通知**兜底（18）：
  本屏 E 行**保留且必须存在**（用户唯一的可控出口）。UI 降级说明：E 行文案不得承诺
  「实时推送」，措辞为「生成完成通知」；若系统授权为「未设置」→ 点击后先走系统授权弹窗，
  再回来时值刷新为真实态
- **NEEDS-4 → App 内注销流程**（§7 #4，**2026-10-02 闭合**）：web v2.65.0 上线
  `POST /api/auth/delete-account`（无请求体、立即生效、身份字段清空匿名化、吊销全部会话）。
  实际契约**没有**原先向服务端要的凭据复核/冷静期/撤销 ⇒ 本屏按真实契约收敛为两步
  （Dialog → POST → 分流），密码框与受理态从规格里删除（服务端没有这个位，
  客户端预演的那套不存在）。
- **本地通知/下载能力位与门 1 的关系**：C 行随 D12 放行；E 行不随（通知免费且属功能可见性）
- **可空规则**：`entitlements` 不可得 → 本屏不显任何能力（不显「未知」）；缓存占用取不到 → `--`
- **分页/刷新**：无。下拉刷新在本屏**不提供**（无可刷新的服务端内容，禁用系统刷新控件）

## 8. 边界与文案

- **截断**：标签 1 行；右值 1 行（URL/邮箱不截断，AX 换行）；Dialog 正文按条换行
- **零值/极值**：缓存 = 0 → 右值「0 MB」且点击后 Toast「已经很干净了」并**不**弹 Dialog；
  缓存 >1 GB → 显示「1.2 GB」（一位小数，`type.mono`）；播放队列 >200（登出影响的队列规模）
  不在 Dialog 里报数（数字随时间变化，告知里放数字会失真）
- **并发冲突**：
  - 登出 Dialog 打开期间：其他手势与行不可交互（模态，17-S7）；若此刻收到 401 → 本地登出
    与用户确认的登出收敛为一次清理（幂等，不重复清两遍、不重复发 logout）
  - 清缓存与播放中：正在播的曲目的试听缓存**不删**（删了会掐断播放），Dialog 正文不必说明该细节，
    但实现须如此（否则出现「清了缓存歌突然不出声」）
  - 主题切换与 02 播放器全屏态同时存在 → 主题立即生效，播放器封面铺底逻辑不受影响（02 §9 依赖
    封面色而非主题色）
- **D12**：本屏无余额、无充值、无套餐购买；「会员」入口只在 04/11/13，不在此重复（避免设置页
  变成营销位）。**禁止**出现「升级解锁更多」类行
- **文案清单**：`设置` / `外观` / `主题` / `跟随系统` / `浅` / `深` / `播放与网络` /
