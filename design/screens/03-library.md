# 03 · 曲库（级联筛选 + 曲目列表）

> G1 方向稿，**2026-10-02 修订**：`.searchable` 搜索迁出至 25 搜索页签（04 §2）；
> 本屏回归「浏览+筛选」纯职能，并接受 `LibraryPreset` 预填（§7）。
> 核心体验：web 端 `TaxonomyCascadeMenu` 三级级联的移动端转译。
> 数据源：`GET /api/library/taxonomy` + `GET /api/tracks`（多维筛选）。

## 1. 布局总览

```
┌─────────────────────────────────────┐
│ 曲库                                 │  导航条：大标题「曲库」，
│                                     │  页签根屏（无返回钮、无品牌位、
│                                     │  无搜索栏——搜索在 25 页签）
│ [场景⌄] [情绪⌄] [风格⌄] [器乐⌄] [+] │  筛选条横滑（§2）
│ ─ 已选：咖啡馆 ✕  平静 ✕ ─ 清除全部  │  已选 chips 行（有筛选时出现）
│ 共 1,248 首              [排序 ⌄]   │  结果计数 + 排序
│ ┌─────────────────────────────┐    │
│ │ TrackRow                    │    │  曲目行（§4）
│ │ TrackRow                    │    │
│ │ …（分页加载）                 │    │
│ └─────────────────────────────┘    │
└─────────────────────────────────────┘
     （MiniPlayer 是 04 §4 的 tabViewBottomAccessory，
       由外壳承载、不占本屏布局位）
```

## 2. 级联筛选（本屏灵魂）

- 筛选维度 chips 横滑：场景 / 情绪 / 风格（genre→subgenre→三级延伸）/ 器乐 / 能量 /
  人声 / BPM / 时长。「+」展开全部维度
- 点 chip → 底部弹起**级联选择面板**（modal sheet，占屏 70%）：
  - 风格维度为三栏级联：一级大类 → 二级 subgenre → 三级延伸风格
    （对齐 web 三级级联语义；左栏选中右栏刷新，`duration.fast`）
  - 其余维度为单栏多选网格
  - 面板顶部：搜索该维度词条；底部：「清除」「完成（已选 n）」胶囊钮
- 已选值回显为 chips 行（`color.selectedBg` 底 + `color.selected` 字 + ✕——
  web v2.65.0 去橙化选中档，见 design/README「与 web 的统一设计语言」），
  支持单独移除与「清除全部」
- 筛选变更 → 列表顶部刷新（下拉骨架行），计数同步更新
- 无结果：空态插画 + 「试试放宽条件」+ 一键清除按钮

## 3. 搜索（已迁出至 25 页签）

- 本屏**不再持有 `.searchable`**：全局搜索 = 「搜索」页签（25 屏，04 §2 的
  `Tab(role:.search)`）；搜索历史与防抖账一并迁入 25（25 §3.C）。
- 本屏仍接收**外部带入的检索条件**：通过 `library(preset)` 路由参数携带
  `search` 文本（25 结果态复用件 / 01 搜索档曲库目标发送），此时本屏以
  「已带入条件」呈现——导航条下显示一条可点的「搜索：{query} ✕」回显行
  （`color.surface` 底 + `color.fg` 字，✕ 点击清掉 search、回到筛选列表），
  不渲染常驻搜索框。

## 4. 曲目行（TrackRow）与详情

- 行高 64pt：封面 48pt 圆角 8 / 标题+艺人（subhead 两行截断）/ 时长（mono caption）
- 行内快捷：播放（点行即播，替换队列）/ ♡ 收藏 / ⋯ 菜单（相似曲目 `similarTo`、
  加入歌单、下载[合规放行后]、分享、查看艺人）
- 标签展示：行内第二行显示最多 3 个 displayLabels（scene 用 tagScene 色、mood 用
  tagMood 色，caption 胶囊）
- 长按行 → 预览卡（封面大图 + 波形 + 快捷操作），松手关闭
- 曲目详情：modal 上推半屏 —— 大封面、完整标签、歌词摘要、相似曲目横滑、
  「播放全部相似」CTA

## 5. 排序与分页

- 排序：推荐（默认）/ 最新 / 最热（favoriteCount）/ 时长；底部 sheet 选择
- 分页：滚动到底自动加载（`page` 参数），加载中显示骨架行；到底显示「已加载全部」

## 6. 状态与变体

- 骨架：首屏 8 行骨架（surface 呼吸）
- 错误：整页错误态（error icon + 重试）仅首载失败时；分页失败用 Toast
- 深色：走 token dark；级联面板 elevated 底
- 未登录：浏览与试听正常；♡ / 下载点击 → 登录引导 sheet（邮箱登录入口 + 游客继续）
- Reduce Motion：级联面板滑动退化为淡入

## 7. 与首页/外壳/搜索页签的联动

- 本屏是「曲库」页签的**根屏**（04 §2/§3），同时是 `library(preset)` 路由的
  **复用件**：从 25 分类卡/01 搜索档/01 场景卡进入时，在**发起页签的当前栈**内
  push 本件（页签不切换，04 §3 归属表）。
- `LibraryPreset` 一次性载荷（取数前消费后即弃）可携带：
  - `search` 文本 → §3 回显行形态（仅预填搜索词时使用）；
  - 筛选值（scene/mood/genre/…）→ 已选 chips 行直接呈现对应值；
  - `title` 覆盖（如音乐人名、分类词条名）→ 导航标题替换「曲库」，返回根屏恢复。
- 从首页「AI 音乐人」头像进入：预填 artistId 筛选 + 标题为音乐人名（既有规则不变）。
- 点当前页签回根 / 滚动收起标签栏 / MiniPlayer 落位：全部属外壳（04 §2/§4），
  本屏不自行处理。
