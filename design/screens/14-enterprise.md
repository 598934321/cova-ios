# 14 · 企业服务（介绍 + 联系方式，全部外跳）

> G2 逐屏规格。基准 393×852pt。要点源：`inventory.md` 行 14。
> 合规同 13：D12 —— 无购买/下单；本屏只有**阅读**与**离开 App 去联系**。
> 数据源：**无端点**（`docs/api-contracts.md` 无企业服务/工单/联系端点）→ 内容全为本地静态常量；
> `entitlements.canRequestProjects` 只用于一处措辞判断（§7）。通用态规范源：`17-state-gallery.md`。

## 1. 屏与上下文

- **层级**：push 自 11「企业服务」行；入「我的」页签栈（04 §3）。
- **入口**：① 11「企业服务」；② 13 底部交叉链接（可选，见待裁决 1）；
  ③ 深链 `enterprise`。
- **互链**：三个外跳动作 → Safari / 邮件客户端；屏内锚点「往下看」不跳屏。
- **返回**：退栈回来源；无关闭按钮。
- **登录门槛**：**无**。企业介绍是公开信息；游客完整可看。

## 3. 区块规格

- **A 导航条**：`material.navGlass`，标题 `type.headline`，返回 ≥44pt（TG-03）
- **B 价值主张**：`type.largeTitle` / `color.fg`，左右 `spacing.pageGutter`，下 `spacing.xl`；
  最多 3 行；**不使用渐变文字**（AI 渐变只点睛创作语境，design-language §2）
- **C 能力清单**：2×2 网格（AX 档下 1 列），项：`checkmark.circle`（`color.enterpriseBlue`）+
  `type.callout` / `color.fg`；水平 `spacing.md`、垂直 `spacing.sm`
- **D 案例区（横滑）**：
  - 卡宽 = 屏宽 × 72%（TG-01），`radius.card`，图占 16:10（TG-10）+ 下方一行说明
    `type.subhead` / `color.secondary`（2 行）
  - **案例素材与文案 = 本地常量**，图取 `design/assets/` 或随包静态资源；
    **不得**使用未授权第三方品牌名/logo（G4 合规清单一并核对，见「待裁决 2」）
  - 无案例可放时（内容未定稿）→ 整区不渲染（不留空标题、不留占位图）
- **E 联系区**：
  - 容器：`color.elevated` + 1pt `color.line` 边（TG-04）+ `radius.card`，内边距 `spacing.sm`；
    行间分隔 `color.lineSubtle`
  - E1 邮件行：✉ 符号 `color.enterpriseBlue` + 地址 `type.callout` / `color.fg`（`type.mono`
    呈现邮箱，避免字母歧义）+ 右侧 `chevron.right`；整行一个动作（mailto），≥44pt
  - E2 官网行：`globe` 符号 `color.enterpriseBlue` + 路径文字 `covalink.cn/enterprise`
    （`type.callout` / `color.fg`）+ `arrow.up.right.square`（`color.muted`）；整行一个动作（Safari）
  - **两行都是文字行样式，不做主按钮**（与 13 §3.E 同一合规理由）
- **F 脚注**：`type.caption` / `color.muted`，上下 `spacing.xl`

## 4. 状态变体

- **加载**：**无**（全本地内容）。若 D 区图需从包内异步解码 → 图位 `color.surface` 呼吸（TG-24 邻近）
  不超过 `motion.duration.fast`，超出即为实现问题
- **空态**：不适用；D 区按 §3 整区不渲染规则处理
- **错误**：本屏无网络请求 → 无错误态。**明确禁造**：不得为「拉取案例」预留一个会失败的请求。
  唯一的"失败" = mailto 无可用邮件客户端 / 外跳被系统拒绝 → 由系统处理，App 内**不**提示
- **离线**：完全可用（内容本地）。这是本屏与 13 的共同点，也是它们能作为「无网络依赖合规页」的理由
- **未登录 / 游客**：与登录态**完全一致**（§1）
- **Reduce Motion**：push 转场一帧；横滑为系统滚动；D 卡入场淡入关闭

## 5. 深浅双主题差异

- 蓝色系全部走 `color.enterpriseBlue / enterpriseBlueSoft / enterpriseBlueBorder` 双 mode
- 卡片底 `color.elevated`、分隔 `color.lineSubtle`、正文 `color.fg/secondary/muted`
- 案例图在 Dark 下不加暗化遮罩（图即图）；若图整体偏亮导致刺眼，用 token 化方案解决：
  图片容器 `radius.card` 裁切 + 上下留白增大（`spacing.xl`），**不**加滤镜（AGENTS：品牌资产禁重着色）

## 6. 可访问性

- **朗读顺序**：「企业服务，标题」→ 返回 → B（整段朗读）→「我们能做什么」→ 4 条（「定制曲库，支持」
  形式，✓ 符号 `accessibilityHidden`）→（D 存在时）「谁在用，横向滚动」→ 每卡一行 →
  「怎么开始」→「发送邮件到 enterprise@covalink.cn，链接，将打开邮件程序」→
  「打开官网企业服务页，链接，将在系统浏览器中打开」→ F
- **邮箱可读**：`type.mono` 呈现但朗读时按 `enterprise at covalink cn` 的可读化串
  （或提供 `.accessibilityLabel` 自定义），不逐字母念成长串
- 长按复制：提供自定义操作「复制邮箱地址」，与 VoiceOver 动作合并
- **Dynamic Type**：AX 档下 B 保持 largeTitle（不跟随放大以控行数）、C 由 2 列 → 1 列、
  E 两行各自允许 2 行（邮箱不截断，改用整段换行）
- **触控目标 ≥44pt**：返回 / E1 / E2 / 每张案例卡（若可点，v1.0 不可点 → 无要求）

## 7. 数据契约

| 用途 | 端点 | 说明 |
|---|---|---|
| 价值主张 / 能力清单 / 案例 | **无** | 本地静态常量（随包资源 + 文案表），文件头注明「源：covalink.cn 企业服务页，日期」，G4 前复核 |
| 邮箱地址 | **无**（常量 `enterprise@covalink.cn`） | 由 `inventory.md` 行 14 钉死 |
| 官网路径 | **无**（常量 URL） | `covalink.cn/enterprise`；**不**拼任何用户参数 |
| `entitlements.canRequestProjects` | `GET /api/auth/me` | 仅用于**已登录且该值为 true** 时，在 E 区上方追加一行「你当前套餐可提交项目需求」`type.caption` / `color.enterpriseBlue`；为 false/缺失 → 该行不渲染 |

- **不得发明的端点**：企业需求提交表单、工单、报价、客服会话在 `docs/api-contracts.md` 中**均不存在**
  → v1.0 **无 App 内表单**（若做表单就必须发明 POST 端点，属红线）。
  「联系」只能靠 mailto / 外跳。这是本屏设计被钉成"阅读页"的唯一原因。
- **NEEDS 关联**：NEEDS-3 未解锁 → `canRequestProjects` 不可得 → 那行不渲染（正常降级，非缺陷）。
  其余 NEEDS 与本屏无关
- **可空规则**：`me` 未取到 → 与游客态一致；本屏不显示任何「未同步」提示（介绍页不该带账号噪声）

## 8. 边界与文案

- **禁词表（同 13）**：`购买` `充值` `报价` `价格` `下单` `立即签约` `免费试用申请` → 不得出现
- **允许措辞**：`企业服务` `为品牌、平台与团队提供可商用的 AI 音乐与授权` `我们能做什么`
  `谁在用` `怎么开始` `发送邮件` `在官网了解` `你当前套餐可提交项目需求`
- **截断**：B 3 行；C 每项 1 行；D 说明 2 行；E1/E2 邮箱与路径**不截断**（AX 下换行，
  常规档下若宽度不足则字号降一档而非截断——地址截断即失效）
- **极值**：案例 >6 → 只渲染前 6（横滑不宜长）；案例 = 0 → 整区不渲染
- **并发**：无（无状态写）
- **文案清单**：见上「允许措辞」+ `复制邮箱地址` + `长按复制`

## 9. 验收判据

- [ ] 本屏**零网络请求**（网络面板取证：进出本屏无任何请求，包含 `me` 的静默刷新也不由本屏发起）
- [ ] 屏内无主按钮样式控件、无表单、无价格/下单字样（禁词扫描命中 0）
- [ ] E1 唤起邮件程序且收件人已填；E2 在 Safari 打开；两者都不内嵌 WebView
- [ ] 游客与登录者所见一致，唯一差异是 `canRequestProjects == true` 时多一行提示
- [ ] D 区在素材未定稿时整区不渲染（不出现「敬请期待」或占位灰图）
- [ ] 邮箱/URL 在最小字号档下仍完整可读不截断
- [ ] 蓝色全部来自 enterpriseBlue 三个 token 的双 mode 值
