> G1 方向稿。基准画板 iPhone 16 Pro 393×852pt。参考：Suno 移动端首页结构 ×
> DeepSeek 极简 × Cova 橙。色值/字号/间距全部取 `tokens.json`，下文以 token 名引用。

## 2. 会话输入卡（本屏灵魂）

- 容器：Liquid Glass 材质，圆角 `card`，内边距 `lg`；浅态 elevated 底 + 玻璃高光边
- 第一行：sparkle 图标（AI 渐变着色）+ 占位文字「想听什么？找歌或做歌，一句话搞定」
  （body / muted）。点击展开为输入态：键盘升起、光标聚焦
- 第二行（chips 行，高 36）：
  - 「找歌」「做歌」模式 chip：胶囊，未选 surface 底/secondary 字；选中 accentSoft 底 /
    accentText 字 + 1pt accent 描边。默认「自动」（不选，由 agent 判断意图）
  - 右侧「深度思考」开关：胶囊 toggle，开启后生成/检索过程展示 thinking 流
    （SSE `thinking` 事件逐条折叠展示，DeepSeek 式）
- 发送按钮：圆形 40pt，品牌渐变 `gradient.brandButton` 底 + 白色 ↑
  （`elevation.primaryButtonShadow`）；输入为空时置灰
- 输入态动效：卡片从静态转为聚焦态，`motion.duration.normal`；键盘联动用系统默认
- 提交后行为：跳转「创作」会话详情（做歌）或会话内嵌推荐结果（找歌）——
  由 agent SSE 流内容决定，首页本身不展示结果

## 3. 今日推荐歌单大卡

- 尺寸：宽 = 屏宽 − 2×pageGutter；高 200pt；圆角 `hero`
- 封面全幅（coverMedia 的 fit/focal 焦点裁剪），底部 45% 深色渐变遮罩
- 遮罩上：歌单名（headline / 白）+ 曲数·总时长（subhead / 白 80%，tabular-nums）
- 右上：玻璃圆形播放钮 44pt（点击即播放整个歌单）
- 点击进歌单详情。数据来源：`GET /api/playlists` 第一条精选

## 4. 场景精选横滑卡

- 卡片 140×140pt，圆角 `card`；封面 + 底部标题条（subhead / fg）
- 横滑间距 `md`，首尾对齐 pageGutter；隐藏滚动条
- 数据来源：playlists 按 scene 分组

## 5. 你的创作（生成候选小卡）

- 双列网格，卡片宽 (屏宽−2×gutter−md)/2，圆角 `card`
- 封面（生成封面或 PixelCard 式像素占位呼吸动画）+ 标题（subhead）+ 状态徽标
  （生成中 `warning` / 完成 `success` / 失败 `error`）
- 未登录/无创作：显示空态引导「用一句话开始你的第一首歌」+ CTA 聚焦会话框

## 6. AI 音乐人专栏

- 圆形头像 64pt 横滑，下方名字 caption / secondary
- 内容源：A01–A15 AI 音乐人（`ai音乐人/` 人设；接口走 `artistId` 筛选 tracks）
- 点击进音乐人曲目列表（曲库页预填 artistId 筛选）

## 7. MiniPlayer（全局悬浮，所有屏共享）

- 位置：底部安全区上 `sm`，左右 pageGutter；高 56pt，胶囊圆角
- Liquid Glass 材质（z 序对齐 `elevation.zOrder` 的 miniPlayer 层）
- 左→右：封面 40pt 圆角 8 / 标题+艺人（subhead，两行截断）/ 播放暂停 28pt /
  下一首 24pt
- 点击主体 → 全屏播放器（底部上滑进入，`duration.page` 弹簧）
- 无播放任务时整卡隐藏

## 8. 状态与变体

- **未登录**：feed 正常（公开内容）；「你的创作」区换空态引导；头像位显「登录」胶囊
- **加载**：首访显示骨架屏（surface 色块呼吸）；分区独立加载
- **错误**：分区级错误条（error 色 icon + 「重试」），不阻塞整页
- **深色**：全部走 token dark 值；玻璃材质系统自适应
- **Reduce Motion**：封面呼吸/渐变动画关闭，直接静态呈现
- **下拉刷新**：系统原生刷新控件，accent 着色

## 9. 交互动效

- 页面进入：分区自下而上错峰淡入（每区延迟 40ms，`duration.normal`）
- 横滑卡：弹簧回弹（系统 scroll 默认）
- 会话卡聚焦：玻璃高光边亮度 +20% 呼吸一次（`duration.slow`）
