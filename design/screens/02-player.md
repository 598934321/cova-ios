# 02 · 播放器（全屏 + MiniPlayer）

> G1 方向稿。参考 Apple Music 沉浸感 + 网易云歌词页气质，材质用 iOS 27 Liquid Glass。
> MiniPlayer 规格见 `01-home.md` §7，此处只定义全屏态。

## 1. 全屏播放器布局（393×852）

```
┌─────────────────────────────────────┐
│  [⌄ 收起]        ⋯ 更多              │  顶部条（无底色）
│                                     │
│      ╭───────────────────╮          │
│      │                     │         │  封面：宽度 = 屏宽 − 2×xxl，
│      │    封面（圆角 hero） │         │  正方形，圆角 28，阴影随封面主色
│      │                     │         │
│      ╰───────────────────╯          │
│                                     │
│  标题（headline）        [♡ 收藏]     │
│  艺人 · 专辑（subhead / secondary）   │
│                                     │
│  ▓▓▓▓▓▓▓░░░░░░░░  波形进度条（§3）    │
│  00:42                    -02:18    │  时间（caption / muted / mono）
│                                     │
│   ⏮    ⏪15    ▶/⏸    15⏩    ⏭      │  传输控制（§4）
│                                     │
│  [循环]  [歌词]  [下载]  [分享]        │  次级操作行（§5）
│                                     │
│  ── 队列 / 歌词 下方面板 ──────────  │  底部面板（§6）
└─────────────────────────────────────┘
```

- **背景**：封面取主色 → 深色化模糊铺底（系统材质 dark + 封面色 30% 叠加），
  封面切换时背景交叉淡入淡出（`duration.hero`）
- **进入/退出**：从 MiniPlayer 连续形变上滑（封面与标题共享元素过渡）；⌄ 或下滑手势收起

## 2. 封面区

- 封面图：cover URL；加载中显示 PixelCard 式像素网格占位（muted 色块呼吸）
- 播放中封面轻微放大 1.0→1.03 呼吸（10s 周期）；暂停回到 1.0
- 点击封面 → 切换歌词态（封面缩小上移，歌词区展开，见 §6）

## 3. 波形进度条

- 数据源：`TrackDto.waveformPeaks[]`；已播放部分 accent 着色，未播放 muted 35%
- 无波形数据时退化为细线进度条（3pt 胶囊轨道）
- 支持拖动 seek（拖动中时间气泡跟随，`mono` 字）；高亮区间
  （`highlightStart/End`）在波形上方加 2pt accent 刻度带

## 4. 传输控制

- 中央播放/暂停钮 64pt 圆形，品牌渐变底白图标（同首页发送钮规范）
- ±15s 快进退：`arrow.counterclockwise 15` / `arrow.clockwise 15`（SF Symbols），28pt
- 上/下一首 32pt；全部触控目标 ≥44pt
- 播放/暂停切换用 `.symbolEffect` 内容过渡

## 5. 次级操作行

- 循环模式：`repeat` → `repeat`+accent 点 → `repeat.1`，三态循环（off→all→one），
  选中态 accentText
- 歌词：切换底部面板内容（歌词/队列）
- 下载：D12 合规放行前隐藏入口；放行后流程 = checkout 确认（余额/幂等）→ 下载
- 分享：系统分享面板（链接 `covalink.cn/tracks/:id`）
- 收藏（封面右侧 ♡）：选中 accent 填充 + 缩放弹跳（`duration.fast`）

## 6. 底部面板（歌词 / 队列）

- 面板占屏高 38%，elevated 底 + 顶部分页指示（两个圆点：歌词 | 队列），左右滑动切换
- **歌词**：静态文本滚动视图（D15，无时间轴），居中 body / fg，行距 1.6；
  无歌词显示「纯音乐 / 暂无歌词」
- **队列**：当前队列 TrackRow 列表，当前播放行 accent 高亮 + 音量条 symbol 动画；
  支持拖动排序与左滑移除

## 7. 锁屏与后台

- MPRemoteCommandCenter：播放/暂停/上下首/seek/±15s
- Now Playing：封面、标题、艺人、时长、播放速率；后台音频会话
  （`UIBackgroundModes: audio`）
- 插拔耳机/来电中断：系统自动 duck，恢复策略 = 来电后自动续播，断耳机暂停

## 8. 生成候选试听态（与曲库播放的差异）

- 私有候选音频：先授权下载到沙盒再本地播（D7）；标题栏下方显示「生成候选 · 仅本人可见」
  胶囊徽标（warning 色）
- 不触发播放上报（非曲库曲目）；无收藏 ♡（收藏走 retention 接口，在候选卡上操作）

## 9. 状态与变体

- 加载/缓冲：中央钮转菊花；封面呼吸暂停
- 错误：Toast（error 色）+ 自动跳下一首（连续 3 次失败停止并提示）

**失败与停止的读法**（G3-e 环 4 实测口径回填，随本屏一并待用户验收；裁决见 `docs/decisions.md` D18）：

> 播放器层源码与评审记录里大量引用的「design §9」就是**本节**；`design/components.md` 另有一个
> §9「徽标与标签」，两者无关 —— 交叉引用时请写全路径，别再留歧义（本仓为此走过一次误读）。

- **「停止自动推进并提示」的唯一触发是连续 3 次计数失败**（网络 / 缺文件 / 引擎 / 媒体 /
  未本地化）。UI 读 `isFailureTerminal` 判它，**不要**用「有没有最近一次失败记录」去猜。
- **取消与过期会话永远不算失败**（用户取消、断网中断、登出换代造成的作废）：既不进 3 次
  累计，也**不开终态**，只留一条「上一次坏在哪」的提示（`lastFailure` 是回显账）。
- **被取消的装载结束后播放器是「停止」** —— 不是加载中、不是暂停、更不是「失败已停止」。
  UI 此时显示「已停止 · 可重播」；用户重播会**真取一次**私有音频，而不是直接命令出声。
- **良性导航 = 保持**：暂停或停止中按 ⏭/⏮，若队列数学只能回到当前项，则不换曲、不动位置、
  不记失败、不进终态（与 §4/§6 的越界保持是同一条规矩）。
- **登出 / 换号 / 释放会连失败账与锁屏回显一起清掉**（D8 防串号）：UI 不得把「已释放」渲染成
  「失败已停止」—— 区分依据是快照的 `tornDown` 字段，不是 `state`。
- 深色/浅色：背景始终走封面色模糊，文字对比度动态校验
- Reduce Motion：封面呼吸与转场形变关闭，退化为淡入淡出
