# 12c · 我的创作（生成资产总览）

> G2 逐屏规格。基准 393×852pt。要点源：`inventory.md` 行 12（同构四屏之一）。
> 骨架基线：`12a-favorites.md` §2–§6；会话行规格：`08-ai-sessions.md` §3.C。
> 数据源：`GET /api/find-my-song/sessions`（api-contracts §4，字段清单未逐列文档化 → 见 §7）。

## 1. 屏与上下文

- **层级**：push 自 04/11；入导航栈。
- **入口**：① 04 抽屉「我的资产 → 创作」；② 11 我的 → 我的创作行；③ 深链 `my-creations`。
- **与 08 的职责划分（本屏存在的前提，必须钉清）**：
  | | 08 会话列表 | 12c 我的创作 |
  |---|---|---|
  | 心智 | 「回到我那句话」——对话续作 | 「我做出了什么」——成果总览 |
  | 主体 | 全量会话行（按时间） | 最近 3 个会话 + 收藏的生成物（若可） + 成果计数 |
  | 动作 | 新会话 / 删除 | 只读浏览 + 跳 08 或 09 |
  若两者最终被合并（08 待裁决 5），本屏退化为 08 的别名路由，本文件随之回收。
- **互链**：会话行 → 09；「查看全部创作」→ 08；收藏生成物卡 → 02 试听态 / 09 来源会话。
- **返回**：同 12a。**登录门槛**：需登录（同 08）。

## 3. 区块规格

- **A 导航条**：`material.navGlass`；标题 `type.headline`；**无右侧动作**（本屏只读，
  删除/重命名一律在 08/09 处理，避免同一资源两处写入口径不一）
- **B 摘要行**：`type.subhead` / `color.muted`，`type.mono` 数字，左右 `spacing.pageGutter`，
  下 `spacing.md`。口径见 §7（两个数字的可用性独立降级，不整行一起消失）
- **C 分组标题**：`type.caption` / `color.muted`，左右 `spacing.pageGutter`，下 `spacing.md`
- **D 会话行**：完全复用 `08-ai-sessions.md` §3.C（含 48 封面、进度环、`spacing.md` 内边距、
  最小高 64、分隔 `color.lineSubtle` 1pt）；差异：**不渲染 ⋯ 菜单与左滑动作**（只读）
- **E 「查看全部创作」**：文字钮，`type.callout` / `color.accentText`，居中，
  上下内边距 `spacing.md`（≥44pt 热区 TG-03）；仅当会话数 > 3 时出现
- **F 收藏的版本（横滑 CandidateCard）**：
  - 卡：`../components.md` §5 单卡规格——宽 = 屏宽 × 46%（TG-01 比例档）、封面 1:1（TG-10）、
    标题 `type.subhead` 2 行、状态徽标 §9、玻璃播放钮（TG-22）
  - 横滑间距 `spacing.md`，首尾对齐 `spacing.pageGutter`，隐藏滚动条
  - **整区的显示条件 = NEEDS-11 解锁**（§7）；未解锁时标题与内容一并消失（不留空标题、不留说明）

## 4. 状态变体

- **加载（首访）**：B 一条骨架；D 三行 08 式骨架；F **不骨架**（该区可能根本不存在，
  骨架会制造「应该有」的错觉）
- **空态（两种，分别定义）**：
  1. **无会话**（新用户）→ 整屏 17-S2：插画位 + 「还没有你的创作」+
     「一句话就能开始：说场景、说情绪、说时长」+ 主 CTA「开始新会话」→ 先 `POST sessions` 再进 09
     （与 08 §4 同一动作，文案一致）
  2. **有会话但 F 无数据** → 只隐藏 F 区，不做空态（D 已经承载内容）
- **错误**：`GET sessions` 首载失败 → 整屏错误态（同 08 文案「创作列表没取到」+「重试」）；
  下拉刷新失败 → Toast；F 区数据失败 → 静默隐藏该区（加分区块，不打扰）
- **离线**：有缓存 → D 正常 + 17-S4 离线条「离线，展示上次内容」；无缓存 → 整屏
  「离线：创作需要联网」
- **未登录 / 游客**：不可达（同 08 §1）；他端登出 → 回落 17-S6
- **Reduce Motion**：同 12a（错峰淡入、滑动弹回、静态占位）；F 横滑弹簧回弹由系统滚动承接

## 5. 深浅双主题差异

- 同 12a：纯中性色 token 双值 + `material.navGlass`；F 区玻璃播放钮系统自适应
- 「AI」语义点睛：仅 D 区无封面时的 `sparkles` 占位符号可用 `gradient.ai`（design-language §2：
  AI 渐变只用于创作入口与 agent 文字）——**本屏标题不加渐变**（避免与 04 抽屉项重复点睛）

## 6. 可访问性

- **朗读顺序**：「我的创作，标题」→ 返回 → B 摘要（「12 个作品，3 个会话」）→
  「最近创作」→ 每行**单元素**「<标题>，<摘要>，<相对时间>，按钮」（无 ⋯ 元素）→
  （>3 时）「查看全部创作，按钮」→（F 存在时）「收藏的版本，横向滚动」→ 每卡
  「<标题>，<状态>，试听 按钮」
- **Dynamic Type**：AX 档下 D 行摘要 2 行（同 08）、B 摘要 2 行、F 卡宽由 46% → 68%
  （一屏只露一张多，避免文字挤压）；E 文字钮保持单行
- **触控目标 ≥44pt**：返回 / 每条 D 行 / E 钮 / 每张 F 卡及其播放钮（TG-22 视觉 + 扩展热区）/
  空态 CTA / 重试钮

## 7. 数据契约

| 用途 | 端点 | 说明 |
|---|---|---|
| D 会话行 | `GET /api/find-my-song/sessions` | 与 08 同请求；本屏只取最近 3 条（客户端切片，**不**发明 `?limit=3`） |
| B「N 个会话」 | 同上响应的条目数 | 后端无 count 字段 → 本地条目数；若后端将来只返回前 50 条，则本数字口径为「最近 50 内」——**不**加「+」修饰 |
| B「M 个作品」 | **无端点** | 需要「我的生成物总数」聚合端点；契约（api-contracts §4）无此端点 → **v1.0 不渲染该数字**，摘要退化为「N 个会话」。见「待裁决 1」 |
| F 收藏的版本 | **无端点** + NEEDS-11 | 生成候选的收藏通过 `PATCH /api/media/references/:id/retention` 写入，但**没有**「列出我收藏的生成物」端点。`GET /api/favorites` 会混入 note 条目（NEEDS-11），未解锁前无法安全解码 → **F 区 v1.0 整区不渲染** |

- **字段依赖与降级**（D 区，与 08 §7 完全同源，逐条同规则）：标题未文档化 → 「未命名会话」；
  摘要未文档化 → 不渲染第二行；时间未文档化 → 不渲染；封面未文档化 → `sparkles` 占位；
  **本屏不渲染进度环**（只读总览，进行中的判定留给 08/09，避免两处并发轮询）
- **F 区解锁后的数据源与降级**（写在这里以便届时不再重新设计）：
  1. 若 NEEDS-11 以「`GET /api/favorites` 增类型判别字段」的形式解决 → F 区消费 `source == "note"`
     条目，字段以届时契约为准（`noteId` + 可解码的候选投影）；
  2. 在此之前，用户想找「收藏过的版本」的兜底路径：09 候选卡上的 ♡ 态 + 08 会话回溯
     ——**这就是 F 区必须整区隐藏而不是显示「暂不可用」的原因**（不制造坏路径）
- **刷新/分页**：进入本屏不自动重取（缓存 ≤ 5min，TG-09）；下拉刷新同时刷新 D 与 B；
  无分页（同 08 口径）
- **不得发明的字段/端点**（本屏是最容易「顺手造一个 /api/my-creations」的地方，明令禁止）：
  `works`、`creations`、`generated-tracks`、`?limit=`、`total` 均**不在契约中**

## 8. 边界与文案

- **截断**：D 行标题 1 行、摘要 1 行（AX 2 行）；F 卡标题 2 行
- **相对时间**：同 08 §8 口径
- **零结果**：见 §4 两种空态；会话数 = 1 或 2 时不出现 E 钮、不留空隙（分组自适应）
- **极值**：会话 >50（后端列表上限口径未文档化）→ B 摘要仍显本地条目数，并在 08 里承担完整浏览；
  **不**显示「共 50+」类模糊表述
- **并发冲突**：
  - 本屏与 08 共享同一份缓存：09 内新建会话 → 返回 08 → 本屏下次进入显示最新 3 条
  - 在本屏停留期间他端删除会话 → 点进 09 得 404 → 09 错误态（08 §8 同文案），返回后本屏静默移除该行
  - 下拉刷新与「查看全部创作」跳转互不冲突（导航优先，刷新结果回来后仅更新缓存）
- **零余额 / D12**：无「作品解锁 / 购买版权 / 下载全部」任何字样；F 卡上的下载位同 12a/07 隐藏
- **文案清单**（除 12a/08 共有项外新增）：`我的创作` / `最近创作` / `查看全部创作` / `收藏的版本` /
  `%d 个会话` / `还没有你的创作`（与 08 同串）/ `开始新会话`（同串）/ `创作列表没取到` /
  `离线：创作需要联网`

## 9. 验收判据

- [ ] F 区（收藏的版本）在 NEEDS-11 未解锁时**完全不存在**（视图树、VoiceOver、截图三处皆无），
      且不出现「暂不可用」「即将上线」类占位文案
- [ ] B 摘要在「作品总数」无端点时只显示「N 个会话」，不出现 M 的占位/猜测值
- [ ] 本屏不发起除 `GET sessions` 之外的任何请求（不发逐会话详情、不发 `?limit=3`）
- [ ] 与 08 共用缓存：09 新会话后回 08 可见，再进 12c 首位为该会话
- [ ] 会话数 ≤3 时无「查看全部创作」钮且布局无空洞
- [ ] D 行只读：无 ⋯、无左滑、无进度环（与 08 的差异是设计意图，不是遗漏）
- [ ] 全部值 token 化，`sparkles` 占位是唯一 AI 渐变落点
